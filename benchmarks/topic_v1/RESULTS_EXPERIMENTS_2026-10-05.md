## Решение

- По умолчанию ничего не включать: ни один автоматический флаг не дал значимого прироста.
- Механизм слияния формулировок работает: прирост даёт **качество формулировок**. Флаг
  `formulations` полезен вызывающему агенту (Claude/Codex через MCP `search_hybrid`): передавать
  2–3 смысловых перефразировки запроса.
- `expand=terms` не использовать. Следующая проверка — формулировки, написанные моделью без
  доступа к ручным (отдельный вариант бенчмарка), прежде чем делать их автоматическими.
