## Вопросы на естественном языке из PARA2 (вход эксперимента E12, 13.10.2026)

Вход эксперимента E12 «режим `long_query` для длинных вопросов» —
[предрегистрация](../PREREGISTRATION_E12_2026-10-13.md), §2. Файлы скопированы без изменений из того же рабочего
каталога координатора; sha256 сверены при копировании.

| Файл | Строк | Что | sha256 |
|---|---|---|---|
| `nl_questions_para2.jsonl` | 117 | по одному вопросу на запрос PARA2 (`TQ-…-2`) | `9434fe2cbfe38b6582975011ef1f02bec7e2f3b3a71e6bdd8206d6e091ae1b21` (байты файла, LF) |
| `nl_questions_para2_task.txt` | 6 | текст задания генератору, без списка запросов | переданный файл (CRLF) `6f4cca51e29064c68469159edde158566ac7a969273ab6f6da059bc209bbea7b`; в репозитории (LF) `416b9fcc9713a6f2b5131d818231fe525442f2057c127a656c55b10e01770fe1` |

Строка — `{"query_id", "question"}`: вопрос на русском, переписанный из запроса `query_id`.

- **Окончания строк.** Текст задания пришёл с окончаниями CRLF. В репозитории `*.txt` хранятся с LF
  (`.gitattributes`), поэтому файл записан с LF. Других отличий нет: замена LF на CRLF возвращает переданный sha256.
- **Когда:** 13.10.2026, до любого прогона E12.
- **Кто:** свежая модель-агент Claude Opus 5.5 без инструментов и без доступа к репозиторию (со слов координатора).
- **Что видел:** только эти 117 запросов PARA2 и текст задания. Истину, выдачу поиска и корпус не видел.
- **Задание** — `nl_questions_para2_task.txt`. После задания шёл список запросов (`query_id<TAB>текст`).
- **Первый запуск** генератора координатор прервал до ответа: в задании вместо части списка стояла заглушка. Засчитан
  только второй запуск, с полным списком.
- **Описание:**
  - все 117 вопросов кончаются «?», 8–13 слов (медиана 9); у самих запросов PARA2 — 4–10 (медиана 7);
  - ни один вопрос не совпадает с запросом;
  - латиница — в 2 строках (`TQ-PC-62-2`, `TQ-MM-RS-2`), цифры — в 1 (`TQ-MM-ELEC-2`); всё это есть в самом запросе;
  - словесный Жаккар «вопрос — запрос»: среднее 0,557, медиана 0,556.
- **Статус:** вход поиска (MODEL_CHOICE эксперимента), не evidence и не метки.
- **Как используются.** Как есть: соответствие заданию не проверяется и не правится.
  `benchmarks/topic_v1/scripts/plans_e12_20261013.py` проверяет sha256 обоих файлов и порядок `query_id` и передаёт
  вопрос в `query` гибридного поиска (системы `nl_strict`, `nl_relax`, `nl_strip`, `nl_relax_strip` эксперимента
  E12). Истина вопроса — истина темы его запроса PARA2. Файлы не правятся.
