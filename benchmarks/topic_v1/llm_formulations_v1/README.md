## Кто, когда, что видел

- **Когда:** 13.10.2026, до любого прогона E6.
- **Кто:** две свежие модели-агента Claude Opus 5.5 без инструментов и без доступа к репозиторию и корпусу.
- **Что видел каждый:** только один вариант формулировки каждой темы. Первый агент — 117 запросов варианта NAME
  (`llm_name.jsonl`), второй — 117 запросов варианта PARA1 (`llm_para1.jsonl`). Ручные перефразировки (другие варианты
  темы), истину, выдачу поиска и тексты корпуса агенты не видели.
- **Статус:** формулировки — вход поиска (MODEL_CHOICE эксперимента), не evidence и не метки.

## Текст задания генератору (одинаковый для обоих агентов, дословно)

> Ты помогаешь агенту искать в корпусе документов (русские и английские книги, диссертации, статьи) по
> Верхнекамскому месторождению калийных солей: геомеханика соляных пород, сдвижение и оседание земной поверхности,
> маркшейдерские наблюдения, гидрогеология, разработка. Поиск гибридный (BM25 + векторный). Для каждого запроса ниже
> напиши ДВЕ другие формулировки того же вопроса, которые помогут найти больше релевантных страниц: другие термины и
> синонимы, раскрытие аббревиатур, как это пишут в учебниках и диссертациях; одна из двух может быть на английском.
> Не добавляй фактов, чисел, имён авторов или названий рудников, которых нет в запросе. Каждая формулировка 3–15 слов.
> Ответ: только JSON Lines … Не используй никакие инструменты и не открывай файлы.

Текст — как его передал координатор; многоточие стоит в переданном тексте (на его месте — формат строки ответа, как в
таблице выше). Список запросов шёл после задания.

## Как используются

`benchmarks/topic_v1/scripts/plans_20261013.py` проверяет sha256 и передаёт `f1`, `f2` в поле `formulations` гибридного
поиска (система `llm3` эксперимента E6). Файлы не правятся: исправление — новая версия каталога (`llm_formulations_v2`).
