# Импорт исторических меток H (gate H0, 05.10.2026)

Технический идемпотентный импорт 60 исторических меток релевантности H из замороженной выборки
[H_REVIEW_SAMPLE_T1.md](../H_REVIEW_SAMPLE_T1.md) (SHA-256 `4425711b…dcd9e4`, совпадает с
[freeze 30.09](../H_REVIEW_FREEZE_2026-09-30.json)) с происхождением из передачи владельца `VKM_CLAUDE_HANDOFF_2026-10-05`.
Все 60 H и все локаторы сохранены без изменений (`VKM-SRC-023:r0076` остаётся rendered-локатором; строки 3 и 55 —
одна страница разных тем). Единственный источник значения H — замороженная выборка. Пояснения `rationale_ru` —
пересказ владельца по историческому sidecar [H_REVIEW_NOTES_2026-09-30.md](../H_REVIEW_NOTES_2026-09-30.md);
сейчас они не перепроверялись по оригиналам. Метки не новые, не независимые, не слепые и не выполнены человеком:
freeze фиксирует `DEVIATION_ORIGINAL_TARGET_GRADES_EXPOSED_TO_SUBAGENT`. H=3 означает только тематическую
релевантность странице, а не достоверность чисел, применимость, scientific admission или квалификацию извлечения.
Метки не являются gold для S26. `hscore` не запускался, пул qrels не открывался. Очередь
`SOURCE_FIRST_REVIEW_QUEUE.jsonl` (59 страниц, все 60 пар) — задел для будущей отдельной проверки по оригиналам,
**не слепой пакет**. Новые проверки оригиналов — `NOT_RUN`.

Состав: `handoff_2026-10-05/` — побайтные копии файлов передачи (хеши закреплены в скрипте и в `SHA256SUMS`);
`H_REVIEW_T1_IMPORTED.jsonl`, `SOURCE_FIRST_REVIEW_QUEUE.jsonl`, [IMPORT_RECEIPT.json](IMPORT_RECEIPT.json) —
результат [скрипта импорта](../scripts/import_h_review_2026_10_05.py) (`build` / `check`);
`VERBATIM_CHECK.json` — проверка текстов импорта на дословные совпадения с текстами страниц и цитатами PRIVATE
(только хеши и счётчики). Индекс `../SHA256SUMS` не расширялся: он закрепляет предрегистрацию topic_v1 и
проверяется nightly на CORE только с файлами набора.
