# TERM_DICTIONARY_V1 — предрегистрация: помогает ли поиску формулировка на другом языке

Агент TR, 29.09.2026. Документ зафиксирован **до первой оценки** обеих систем: до него не посчитано ни одной метрики
с переводом запроса и без него. sha256 документа — в [`PREREGISTRATION.sha256`](PREREGISTRATION.sha256) и в квитанции
`docs/corpus_platform/receipts/nav_term_dictionary.json`. Отступления перечисляются в `RESULTS.md`, раздел
«Отступления», с причиной.

## 1. Вопросы

Словарь терминов NAV (`term_translations`, правило `term_translations_v1`) даёт запросу формулировку на другом языке:
функция `translate_query` заменяет термины запроса их переводами (пары с оценкой ≥ 0,8, покрытие ≥ половины
знаменательных слов; иначе перевода нет).

- **Q1.** Досье `reconstruct_topic`: добавляет ли формулировка `translation` страницы-свидетельства в список страниц
  досье или вредит ему?
- **Q2.** Гибридный поиск: помогают ли запросу дополнительные ветви RRF для перевода (флаг `translate`)?

Правило решения (§6) выбирает значения по умолчанию: `topic.TRANSLATE_DEFAULT` и флаг `translate` гибридного поиска.
Принцип задачи: оставить, только если не вредит.

## 3. Поисковый движок обеих систем (локальная копия схемы E)

API CORE агенту недоступен (система разрешений отказала в чтении с CORE), поэтому обе системы каждой пары считаются
**одним и тем же** локальным движком P-E на WORKSTATION — копией развёрнутой схемы E бенчмарка V1:

1. **BM25** — лабораторный BM25 (анализатор `retrieval_lab.textproc.analyze`, k1 = 1,2, b = 0,75) по единицам снимка
   (`units_final` рабочего каталога V1, без BIB_ENTRY) → страницы по лучшей единице, топ-100.
2. **Dense** — jina-embeddings-v5-text-nano (контур `nano-gpu` бенчмарка V2: векторы документов V2, запрос с префиксом
   модели, кодирование на RTX) по единицам dense-индекса, точный косинус → страницы, топ-100, группы дублей свёрнуты.
3. **RRF** (k = 60) двух списков.
4. **Late** — mLateOn (спецификация L2): токены запроса кодируются локально, MaxSim по пакету токенов V1 (единицы
   страниц RRF-топ-100, страница = максимум по её единицам без BIB_ENTRY), перестановка топ-100 (`late_rescore` V1).
5. **Ярусы досье** — проход по ядру ВКМ ограничивает все стадии единицами источников ядра (как фильтр OpenSearch).
6. **Расширение (Q2)** — перевод даёт свои ветви BM25 и dense в том же RRF; late оценивает исходный запрос (как в коде
   `search.hybrid`).

Контрольная строка (не входит в решение): P-E на исходных запросах против `E|rrf-lab>late@100` из V1 (nDCG@10
0,328 на V и 0,722 на P).

| Пара | База | Лечение |

## 5. Метрики и статистика

- **Q1** (функции `retrieval_lab.topic_bench`, ранжирование = `pages.core`, затем `pages.rest`):
  - основная — `page_recall@50`;
  - вторичные — `page_recall@20`, `mrr@50`, `success@10`;
  - единица анализа — тема (среднее по её трём запросам), n = 117.
- **Q2** (функции `retrieval_lab.metrics`, релевантно — оценка ≥ 2, неразмеченное — нерелевантно):
  - основная — nDCG@10 на V;
  - вторичные — nDCG@10 на P, R@50 на V и P, MRR@10;
  - единица — запрос, 144 запроса;
  - judged@10 обеих систем на P показывается.
- **Тест** — парная рандомизация со сменой знаков (10 000 перестановок, seed 20260929), бутстреп 95 % ДИ.
- **Срезы** (описательно, без решения):
  - Q1 — «смешанные» темы: среди источников целей есть источник с английской основной работой (`works.languages`);
  - Q1 и Q2 — запросы, у которых перевод применён;
  - Q2 — межъязыковые запросы `T-RUEN-*` и `T-ENRU-*` (16).

## 6. Правило решения («оставить, только если не вредит»)

- **Q1:** `TRANSLATE_DEFAULT = True`, если одновременно:
  - Δ `page_recall@50` (D1 − D0) ≥ −0,005 и нет значимого ухудшения (p ≥ 0,05 при Δ < 0);
  - Δ `mrr@50` не хуже того же порога.

  Иначе `False`; флаг остаётся доступным.
- **Q2:** флаг `translate` включается по умолчанию, только если на V **и** на P одновременно:
  - Δ nDCG@10 ≥ −0,005 без значимого ухудшения;
  - Δ R@50 ≥ −0,005 без значимого ухудшения.

  Иначе по умолчанию выключен.
- Включение на CORE — решение координатора или пользователя после развёртывания. Измерение сделано локальной копией
  движка, а не развёрнутым сервисом.
