# Независимая проверка реконструированного датасета СКРУ-1 v3.1

## Вердикт

**CONDITIONAL GO — датасет допускается как фундамент для разработки алгоритма, но не как производственный журнал.**

Независимый аудит включает 42 проверки. Пройдено 42, провалено 0, критических дефектов 0.

## Что исправлено

1. Число 1665 больше не воспроизводится искусственным добором строк. Оно хранится только как опубликованная характеристика исходного интегрального слоя: 1665 строк и 257 полей. Реконструированный слой содержит 1395 записей, естественно возникших из 12 отдельных слоёв-кандидатов.
2. Геометрия извлекается из чистой красной векторной накладки рисунка 13. Старое условие `gray < 120` и построение геометрии по карте оседаний удалены.
3. Для карты оседаний зафиксирован только подтверждённый год 2022. Поле точной даты оставлено пустым (`NULL`).
4. Опубликованные `Disp_min`, `Disp_mean`, `Disp_max`, глубина кровли, ширины камер и целиков, коэффициент нагрузки и осевое расстояние реально участвуют в реконструкции. Максимальный остаток по точным якорям равен 0 в пределах машинной точности.
5. Нивелирная сеть уравнивается по наблюдённым превышениям и независимым ограничениям исходных реперов. Истинные синтетические высоты используются только для оценки качества после уравнивания.
6. Скрипт самодостаточен: принимает `--source-docx`, сам извлекает `word/media`, сохраняет хэш источника и не зависит от старого каталога `/mnt/data/filatova_unpacked`.
7. Сетка 50 м геометрически обрезана по контуру. Площадь вне контура и непокрытая площадь равны нулю; ошибка баланса площади составляет около `1.86e-08 м²`.
8. Все 45 опубликованных якорей имеют отдельную запись пространственного связывания. Ни одна принятая связь не превышает объявленную неопределённость.
9. После исправления шкалы `k_o` напрямую оцифровано 74.5% площади. Ещё 24.7% восстановлено только в пределах 250 м от достоверного донора. Оставшиеся 0.9% честно хранятся как пропуски.
10. У опорных реперов одновременно равны нулю накопленное оседание и скорость.
11. GNSS-контур больше не состоит целиком из `accepted`: присутствуют 963 принятые и 87 предупреждающих эпох. Эмпирическое покрытие 95%-го интервала составляет 97.9%, RMSE — 4.51 мм.
12. InSAR-ряд задан относительно первой съёмки: у всех 100 отражателей первая эпоха равна нулю. QC полностью согласован с когерентностью; эмпирическое покрытие 95%-го интервала — 97.7%, RMSE — 7.98 мм.
13. Добавлены и независимо пересчитаны таблицы горизонтальных сдвижений, горизонтальных деформаций, наклонов, кривизны, скоростей оседания и профильной кинематики.
14. Независимый повторный запуск построителя дал побитово идентичные ключевые CSV-таблицы.

## Что невозможно закрыть вычислениями без первичных материалов

Остаются четыре внешних ограничения:

1. Нет исходных TAB/Excel-файлов и полного набора 1665 производственных записей. Поэтому точное членство каждого исходного полигона в слоях восстановить нельзя.
2. Нет официального ключа перехода из местной системы координат. Рабочими остаются локальные X/Y; обзорная геопривязка не используется для инженерных измерений.
3. Нет утверждённых предприятием предельных деформаций. Соответствующие поля остаются `NULL` или `inactive`.
4. Нет реальных повторных циклов для внешней проверки прогнозной модели. Синтетика используется для разработки алгоритма, стресс-тестов и проверки вычислительной устойчивости.

Подробные результаты находятся в `tables/audit_checks.csv`, `tables/issue_register.csv`, `tables/known_limitations.csv` и `audit_metrics.json`.
