Build a deterministic, auditable research system for forecasting land-surface subsidence using reconstructed and synthetic SKRU-1 data, while preserving strict scientific boundaries.

## Non-negotiable path rule

Never assume `/mnt/data`, `E:\Диплом`, a user home path or a drive letter. Resolve the repository root and use relative manifest paths.

## Input verification gate

Before changing code:

```bash
python scripts/verify_inputs.py --root .
```

Stop if any file is missing, has a size mismatch or has a SHA-256 mismatch.

## Scientific constraints

- no random row split;
- no tuning on test;
- no hidden truth, generator parameters, future regime or terminal map as features;
- no production accuracy claims from reconstructed/synthetic data;
- no enterprise risk thresholds unless supplied;
- preserve InSAR LOS semantics;
- report complexity and seed variability for DL models;
- general LLMs are support tools, not primary numerical forecasters.

## Model programme

Implement model families stage-by-stage. Do not start with the largest transformer. Every model must be compared against B1 and B6 under the same frozen split.

## Definition of done for each experiment

- config is saved;
- data/feature/target hashes are saved;
- predictions for every eligible row are saved;
- metrics and interval metrics are saved;
- runtime, parameter count and memory are saved;
- at least five seeds for DL/FM unless technically impossible and explicitly documented;
- validation selection and test evaluation are separate;
- error slices are generated;
- no forbidden feature is present;
- human report contains concrete paths and hashes.

## LLM/RAG layer

Any statement generated by an LLM must cite a project source or a machine-readable result. The LLM cannot invent measurements, thresholds, model wins or safety decisions.
