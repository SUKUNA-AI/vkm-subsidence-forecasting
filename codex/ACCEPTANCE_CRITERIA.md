# Acceptance Criteria v2

- input verification: 5/5 bootstrap and 11/11 primary sources PASS;
- no absolute operational paths;
- data and contracts frozen before model screening;
- all complex models compared to B1 and B6;
- no test tuning;
- DL models: at least five seeds, parameter/runtime/memory report;
- graph models: unseen-profile/zone evaluation;
- foundation models: exact weights/licence/hash recorded;
- LLM layer: source-grounded, no direct safety authority;
- final candidate selected by temporal + spatial + transition + OOD criteria, not by a single R2.
