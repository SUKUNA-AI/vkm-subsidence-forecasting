# Phase 03 — deep temporal models

Implement LSTM, GRU, TCN, DeepAR, N-BEATS, N-HiTS, TSMixer, TFT, PatchTST and iTransformer behind a common interface. Use causal inputs only, masks for missing cycles, actual time deltas and at least five seeds. Record parameters, runtime, memory and seed variability. Select hyperparameters on validation only.
