# Phase 05 — time-series foundation models and LLM support

Evaluate locally runnable time-series foundation models in zero-shot first, then few-shot only if the protocol permits. Candidate families include Chronos-like, TimesFM-like, Moirai/Lag-Llama-like and tabular foundation models. Verify licences and exact model hashes.

Build an optional LLM/RAG layer for source-grounded metadata extraction, experiment report drafting and Error Atlas explanation. It must never be the primary numeric forecaster and must never assign enterprise risk classes.
