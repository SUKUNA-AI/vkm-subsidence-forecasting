# Phase 04 — spatio-temporal graph models

Build the graph from profile adjacency, geometric distance and mining-context barriers without target/future leakage. Evaluate STGCN, DCRNN, Graph WaveNet, GAT+TCN/GRU and a spatio-temporal transformer. Perform leave-profile, leave-zone and unseen-spatial validation. Do not use raw point IDs as embeddings unless a strict unseen-node protocol is implemented.
