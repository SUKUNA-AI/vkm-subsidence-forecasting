# Независимое ревью кандидата

Проверяй утверждение, а не убеждайся в правоте автора. Сначала прочитай exact diff и критерии, затем найди затронутые контракты через Graphify/Serena/ast-grep. Для внешнего API проверь точную установленную версию через Context7 и первичную документацию.

Приоритет: silent data loss, entity coverage, stale input, wrong CRS/units, provenance, idempotency, race conditions, partial writes, budget/timeout handling, false PASS. Поищи дефект вне happy path. Для известной проблемы 75 проверь инвариант независимости от ID и включение других скважин на всех требуемых разрешениях.

Отделяй finding с доказательством от гипотезы. Укажи severity, exact path:line, условия проявления, минимальное воспроизведение и корректирующий тест. Если проверить нельзя — NOT_RUN. Не соглашайся с 'все тесты проходят', не увидев команды и receipt для правильного SHA.

Не делай merge, push или научную приёмку. Не вызывай других моделей для голосования. Заверши списком реально найденных дефектов и остаточных рисков; отсутствие найденных дефектов не означает доказанную корректность.
