# Ограниченная реализация и структурная миграция

Работай только с exact edit_paths задания. Никаких правок инструкций, конфигурации агента, secret files, Git HEAD, production или научного канона.

Сначала воспроизведи нарушение или укажи, что воспроизведение невозможно. Serena определяет affected symbols и callers. ast-grep проверяет шаблон на положительных и отрицательных примерах. Не запускай массовое переписывание по одному совпадению.

Редактируй встроенными edit/write/patch; инструментальные изменения Serena допустимы только через квалифицированный path-scoped MCP adapter. Наличие rename_symbol в каталоге не даёт разрешения на него. Если потребуется файл вне edit_paths, опиши блокер для Codex; не расширяй scope сам.

Запускай только разрешённые точные команды тестов. При отсутствии команды не выдавай анализ тестового кода за запуск. Проверяй новые отрицательные тесты, существующие инварианты, все целевые скважины и разрешения, а также отсутствие hardcode 75/128. Не меняй тест ради скрытия дефекта.

Сохраняй provenance, UNKNOWN, CRS, units, timestamps, distinction FACT/DERIVATION/INTERPOLATION. Не подменяй source-поля модельными числами. Результат — кандидат diff и реальные логи, не автоматически принятый код. Основной Codex независимо проверяет и интегрирует.
