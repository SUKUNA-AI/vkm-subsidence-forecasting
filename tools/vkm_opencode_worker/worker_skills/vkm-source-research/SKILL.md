# Источниковое исследование ВКМ

Научная память уже существует в VKM Corpus / NAV / ScientificReader / evidence. Не создавай новый канон в Graphify или сессии OpenCode.

Сначала проверь существующий результат и локатор. Через vkm_corpus запроси ограниченную тему/страницу/рисунок/таблицу. Поисковая выдача — кандидат. Научное утверждение проверяй по источнику и сохраняй source/work/page/figure, SHA, scope, CRS/frame, units и epistemic role.

Отделяй FACT, DERIVATION, INTERPOLATION, MODEL_CHOICE, ENGINEERING_ASSUMPTION, ANALOGUE, UNKNOWN. Не объявляй агентскую проверку человеческой; не превращай CAD round-trip в геодезическую точность. Скважина 75 не заменяет остальные скважины или другое шахтное поле.

Graphify здесь нужен лишь для связи кода и контракта; его code graph не равен научному графу. Context7 — внешние API, не первоисточник геологии. Внешние MCP-запросы не должны содержать ключи, DSN или избыточные закрытые фрагменты. Пользователь разрешил внутреннюю работу с доступными PRIVATE-материалами: не придумывай повторные запреты на каждый источник, но соблюдай существующие data-policy/publishing границы.

Верни новое ограниченное знание с локаторами либо проверенный отрицательный результат по перечисленным маршрутам. Не пересказывай весь корпус. Не загружай все статьи в контекст и не вызывай OCR при доступном тексте/изображении и существующей извлечённой структуре.
