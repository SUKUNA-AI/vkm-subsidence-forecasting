# Конечная поромеханика с опорной ёмкостью

Модуль `vkm_world.representations.world0.finite_poromechanics` реализует отдельную конечнодеформационную гипотезу. Параметры и тесты синтетические; это не замена текущей малодеформационной истории и не основание отключать её guard.

F — градиент деформации, J=det F>0, V0 [м³] — опорный объём. ζ [м³] — изменение массы жидкости, делённое на опорную плотность, а не текущий поровый объём. Заданы постоянная опорная ёмкость S [м³/Па], α∈[0,1], Jref и абсолютное Pref [Па].

    c = α V0 (J−Jref),    x = ζ−c,
    Ef = x²/(2S) + Pref x,
    p = x/S,             Pabs = Pref+p,
    Pf = −α Pabs cof F.

Ef — энергия элемента [Дж]; API возвращает также плотность W=Ef/V0 [Па]. Массовый потенциал и механическое давление совпадают, поскольку S постоянно. При S(J) эти формулы необходимо вывести заново. Cauchy fluid stress равен −αPabs I. Reference pressure создаёт ненулевую начальную силу; исходное равновесие требует явной нагрузки или initial skeleton stress. Удалять Pref из сил без переноса его работы нельзя.

`evaluate(F,ζ)` возвращает касательную при фиксированном содержимом, `mixed(F,p)` — при фиксированном приращении давления:

    A|ζ = α² V0/S cofF⊗cofF − αPabs ∂cofF/∂F,
    A|p = −αPabs ∂cofF/∂F,
    ∂Pf/∂p = −αcofF,      ∂ζ/∂F = αV0cofF,      ∂ζ/∂p = S.

Для TL assembly плотности P/A умножают на V0 ровно один раз; content и его производные уже относятся ко всему элементу. В пределе малой деформации восстанавливаются знаки Ku−Hp=f и Sdp+Hᵀdu+dtLp=dt source. Геометрическая касательная от Pref остаётся дополнительным initial-stress слагаемым.

Геометрическая гипотеза явно задаёт текущий поровый объём Vp=Vfluid,ref+c. Исходный Vfluid,ref одновременно равен начальному поровому объёму и начальной массе, делённой на выбранную опорную плотность. В дальнейшем эти величины различаются на storage anomaly x. Скелет занимает Vs=V0J−Vp. Применимость ограничена двумя фазами положительного объёма:

    0 < Vfluid,ref < V0 Jref,
    0 < Vp < V0 J,        Vs > 0.

Также проверяются положительная масса и Pabs≥minimum_pressure_Pa. Ничего не обрезается и не перераспределяется автоматически. При α=1 объём скелета постоянен. При α<1 линейная зависимость порового объёма от J является дополнительной геометрической гипотезой; guard лишь исключает противоречивые состояния, но не заменяет полноценное уравнение состояния зёрен. `check_domain=False` пригоден только для формальных локальных производных, не для принятия физического шага.

Пример недопустимого состояния: V0=1 м³, Vfluid,ref=.8 м³, α=.5, J=.3 даёт Vp=.45 м³ при полном объёме .3 м³. Модуль отвергает его, как и нулевой объём скелета. Диагностика содержит current_cell_volume_m3, pore_capacity_m3, solid_volume_m3, porosity.

Синтетический fixture содержит две affine ячейки и фиксированный reference Darcy graph. Это не обновляемая текущая геометрия фильтрации. DG использует точный discrete gradient энергии, но мгновенный endpoint force residual требует проверки сходимости. BE решает endpoint equilibrium и отдельно учитывает алгоритмическую работу; она не объявляется физическим теплом. Обе схемы проверяют массу и restart. Для пути DG проверяется положительность J не только на концах, но и во внутренних экстремумах determinant polynomial.

Тесты проверяют objectivity, производные энергии, mixed tangent, предел малых деформаций, положительность объёмов, работу, закрытую ячейку и restart. Эти проверки не устанавливают full 3D stability, материал рудника, native coupled validation или применимость истории выемки/закладки.
