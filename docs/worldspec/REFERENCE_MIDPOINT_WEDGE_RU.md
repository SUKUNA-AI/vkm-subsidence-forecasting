# Конечная кинематика, память и средняя точка по времени

Этот модуль расширяет существующее численное представление `world0`, а не
вводит новый эмпирический закон соли. Физическая гипотеза и ограничения
[конечно-деформационного LUBBY](FINITE_REFERENCE_LUBBY_RU.md) сохраняются:
`mG=0`, изотропная упругость в выбранной отсчётной конфигурации,
напряжение второй меры Пиолы — Кирхгофа `S`, деформация Грина `E` и
состояния памяти Кельвина `k` и Максвелла `v`. Зависимость вязкостей от
инварианта `S` является модельным выбором. Натурная применимость такой
конечно-деформационной гипотезы этим кодом не устанавливается.

## Область, единицы и состояния

`wedge_adapter.WedgeMesh` задаёт согласованные шестузловые призмы с шестью
точками интегрирования. Координаты и перемещения — метры, плотность —
кг/м³, время — секунды, напряжения и модули — паскали, вязкости — Па·с,
удельные энергии — Дж/м³ отсчётного объёма. Порядок Манделя:
`xx, yy, zz, sqrt(2)xy, sqrt(2)yz, sqrt(2)xz`.

`GroupedLaw` размещает на непересекающихся группах точек исходные законы
LUBBY, Максвелла либо гиперупругую модель Сен-Венана — Кирхгофа. Все точки
должны быть покрыты ровно один раз. Общие узлы передают полные векторы сил;
матрица касательной жёсткости сохраняет возможную несимметрию.

Доля присутствующего материала `a` удовлетворяет `0<a<=1` и один раз
умножает объёмные меры, массу, объёмную нагрузку, внутренние силы и энергию.
Полная пустота, контакт, жидкость и перенос состояния при удалении материала
в этот адаптер не входят. Положительный якобиан и достаточный локальный
критерий Лежандра — Адамара проверяются для каждой группы перед приёмкой.

## Схема средней точки

Пусть `h>0`, `s_m=dev(S_m)`, `q_m=sqrt(3 s_m:s_m/2)`, а вязкости
`eta_K` и `eta_M` вычислены при `q_m`. Для одного шага определяются

```text
E_m = (E_0 + E_1)/2
x = h G_K/(2 eta_K)
a = 1/(1+x), b = x/[2 G_K(1+x)], c = h/(4 eta_M)
k_m = a k_0 + b s_m
v_m = v_0 + c s_m
E_m + E_ref = C_0^{-1} S_m + k_m + v_m
k_1 = 2 k_m - k_0, v_1 = 2 v_m - v_0, S_1 = 2 S_m - S_0
```

Нелинейное уравнение решается по `S_m`; касательная включает производные
обеих вязкостей и не симметризуется. Используется прежний `TLModel.solve`.
`MidpointWedgeModel` меняет интегрирование памяти и аудит работы, сохраняя
пространственный оператор. Для шага нулевой длительности память заморожена.

Точки с ненулевой памятью Кельвина при неподдержанном классическом
касательном операторе в `q=0` и неподтверждённое пересечение этого состояния
отрезком напряжений отклоняются. В линейном пределе дополнительно требуется
`h G_K/(2 eta_K)<=1` и `h G_0/(2 eta_M)<=1`: пассивность слишком крупного
шага сама по себе не исключает неразрешённые временные осцилляции.

## Работа, диссипация и пределы вывода

Для квадратичной запасённой энергии материальный шаг удовлетворяет

```text
Delta Psi = S_m:Delta E - h D_m
D_m = |s_m-2 G_K k_m|²/(2 eta_K) + |s_m|²/(2 eta_M) >= 0.
```

Это дискретное тождество с квадратурой `D_m`; оно не означает точного
интегрирования непрерывной теплоты. Для фиксированной активности и постоянной
узловой нагрузки конечное пространственное представление даёт

```text
W_ext - Delta Psi - h D_m = G - (r_0+r_1):Delta u/2
G = integral[(Delta F Delta S):Delta F] dV_0 / 4.
```

Здесь `r=f_int-f_ext`. Знак `G` не фиксирован; эта величина не является
теплотой и не вычитается при проверке физического энергетического дефекта.
Работа переменных нагрузок, событий, контакта и переноса вещества требует
отдельной постановки. Сходимость по шагу времени проверяется независимо от
дискретного тождества.

## Перенос памяти и проверки

`transfer_point` и `transfer_grouped` явно меняют подпись численного
представления при одинаковых физических коэффициентах и отсчётной
конфигурации. Они сохраняют `u/E/S/k/v/time/Psi` без обнуления памяти;
чужие параметры или несовместимое состояние отклоняются. Неуспешный пробный
шаг оставляет принятое состояние неизменным. Перезапуск проверяет подписи,
геометрию, деформацию, память и замыкание состояния.

Синтетические тесты проверяют полную касательную по разностям, объективность,
силы и моменты, линейный предел прежнего WEDGE-оператора, долю материала,
энергетические тождества, ненулевую память, откат и точный перезапуск.
Независимое интегрирование ОДУ методом DOP853 проверяет второй порядок по
времени и отдельно выводит ошибки работы и диссипации. Непрохождение
порогового уровня этими ошибками не отменяется успешным тождеством.

Ни модуль, ни синтетические тесты не устанавливают начальные поля рудника,
согласованность геологических отметок, натурную валидацию или полную историю
выемки и закладки. Проверка начального мгновенного состояния другим решателем
также не квалифицирует реологическую историю положительной длительности.
