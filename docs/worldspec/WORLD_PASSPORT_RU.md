# Паспорт параметров и законов физических миров и каталог наблюдений (09.10.2026)

Паспорт — реестр того, из чего достраиваются физические миры модулей C1–C4
([WORLD_KERNELS_DESIGN_RU.md](WORLD_KERNELS_DESIGN_RU.md), §2): у каждого параметра — диапазон в СИ, источник и
страница, масштаб, площадка, ветка переноса лаборатория → массив и статус для мира. Каталог наблюдений — реальные
натурные ряды всех площадок ВКМ, по которым потом проверяется прогноз (покрытие ансамбля, NROY, бенчмарк).

Паспорт не утверждает, что какой-либо мир «есть» СКРУ-1, и не заменяет UNKNOWN числами. Всё, что извлечено
автоматически или субагентами, остаётся `AUTO_EXTRACTED_UNREVIEWED`, пока его не проверил человек.

## 2. Как устроен реестр

Сборка: `VKM_RESOURCES_ROOT=<PRIVATE> python scripts/build_world_passport.py --runs high_full double --nav <NAV>`
(`--check` пересобирает в памяти и сравнивает). Выход — `WORLD_PASSPORT/`:

| Файл | Строка |
|---|---|
| `passport_evidence.csv` | одно число из одного источника: значение как напечатано и в СИ (`convert()` этапа 1), класс породы (`material_class()`), масштаб, ветка, площадка, оригинал/пересказ, страница, цитата (только PRIVATE), кластер копий, совпадение с двойной проверкой |
| `world_passport.csv` | модуль × параметр × цель (класс породы, слой, гипотеза, пласт/зона) × группа площадки × ветка: диапазон и квартили в СИ, число evidence и источников, статус для мира и его основание, конфликты, строки переноса |
| `passport_conflicts.csv` | записанные конфликты (Phase 1, C3, законы) и вычисленные: оригиналы разных источников расходятся больше чем втрое |
| `world_objects.csv` | слой объектов: иерархия Phase 1 (рудники, пласты, панели, блоки, скважины, линии) + упоминания из извлечения, новые кандидаты |
| `cited_literature.csv` | за пересказанным числом — запись списка литературы, работа корпуса или внешнего реестра, иначе «получить» |
| `transfer_branches.csv` | ветки A/B/N и множители переноса по параметрам и классам |

**Ветки** (решение пользователя 08.10 — обе ветки как гипотезы, в одно число не схлопываются):
- **A** — лабораторное значение; в массив переносится масштабным коэффициентом (Transfer). Коэффициент — свой
  диапазон или UNKNOWN;
- **B** — эффективное значение, откалиброванное или принятое в опубликованной модели (по оседаниям, конвергенции);
- **N** — норматив или проектное значение: не измерение, отдельная ветка;
- **F / M** — для начального состояния: натурное измерение / расчёт или модельный выбор.

**Статус для мира**:
- `FACT` — натурные данные самого СКРУ-1 из первоисточника;
- `ANALOGUE_VIA_TRANSFER` — другая площадка ВКМ или другое месторождение: только через явный Transfer;
- `SCENARIO_RANGE` — ветки A, B, N, M, пересказ или неизвестный масштаб: маркированный сценарный диапазон;
- `UNKNOWN` — параметр, нужный мирам, без evidence. Строка существует, числа в ней нет.

Если лист C3 или лист законов оценил строку осторожнее, побеждает более осторожная оценка.

Копии одного числа (тот же параметр, цель и значение в нескольких строках) образуют кластер: первоисточник —
`PRIMARY`, пересказы — `COPY_CITED`, то же число у другого производителя — `SAME_NUMBER_OTHER_PRODUCER`. В диапазон
реестра копии второй раз не входят.

## 3. Главные находки (не терять)

- **λ (C3).** «λ массива ВКМ 0,60–0,71» не подтвердилось как свойство массива: это два определения одной школы
  (эффект Кайзера на керне при принятом σv = γH; гидродомкрат у выработки на БКПРУ-2). Гидроразрыв на СКРУ-3
  даёт λ ≈ 1,0, статьи ИГД СО РАН — горизонтальные напряжения в 2–3 раза выше вертикальных. Гипотезы не
  схлопнуты: гидростатика λ = 1 (0,86–1,13), субгидростатика 0,6–0,8, анизотропное поле СКРУ-1 1989 г. (вдоль
  σmax 1,05–1,41, вдоль σmin 0,74–0,91), гидроразрыв 2016 (σmin/σv 1,33–1,85), Динник — только надсолевая толща.
  Единственная точка полного тензора СКРУ-1 — 1989 г. (пересказ, первоисточник вне корпуса).
- **E сильвинита.** Ветка A: лаборатория 5,9–14,6 ГПа (медиана ≈ 10,8). Ветка B: эффективные 0,4–0,9 ГПа, но 7 ГПа
  в модели с явной ползучестью. Перенос лаборатория → массив — главная неопределённость.
- **Длительная прочность** σ∞/σсж: каменная соль 0,60–0,65, сильвинит 0,35–0,40 (СКРУ-1 0,36 при h/d = 2; 0,50 —
  только у плоских образцов h/d = 0,5), карналлит 0,20–0,25. Рекомендуемые для расчётов 0,30 (сильвинит) и 0,16
  (каменная соль) вчетверо ниже лабораторных — конфликт CC-02. Множителя переноса для длительной прочности нет ни
  в одном источнике — UNKNOWN.
- **Ползучесть.** Нортон n ≈ 6–7 (лаборатория; у Ермашова n = 5). Вязкость установившейся ползучести сильвинита:
  лаборатория 1,43·10⁷ МПа·год, станции СКРУ-1 4,6–7,6·10⁷ — массив ползёт в ~4 раза медленнее; у Константиновой
  ядро Абеля по сжатию целиков СКРУ-1 примерно лабораторное — конфликт CC-07. Норматив: Абель α = 0,7,
  δ = 5·10⁻⁴…5·10⁻³.
- **Единые показатели EXT-SRC-010** (Барях и др., 2005) найдены в корпусе (VKM-SRC-042, перевод статьи): функция
  Φ = δt^(1−α)/(1+e^(ρ−βt)); АБ α = 0,9, β = 0,9, ρ = 2,7C + 0,3C^−4,4; КрII 0,85 / 0,9 / 1,8C + 0,3C^−4; Вк 0,9 / 0,3 / 4;
  время завершения сдвижения 500 лет (сильвинит) и 200 (карналлит). Это параметры отработанного пласта (ветка B),
  откалиброванные по 12 профильным линиям без названия рудников: если эти линии пойдут в проверку прогноза, будет
  утечка — до бенчмарка линии калибровки нужно установить.
- **Масштабный эффект** противоречив (CC-01): структурное ослабление у Лебедевой (коэффициент 15, MODEL_CHOICE)
  против роста прочности с размером у Баряха и Соловьёва (+23 %); норматив даёт множитель 1,12.
- **Закладка (C4).** UNKNOWN: параметры закона уплотнения, модули, старение между 1 и 18 годами, фактические
  коэффициент заполнения, усадка и зазор по зонам СКРУ-1. Ошибка досье исправлена: зазор 10–13 см на БКПРУ-1 —
  щель между целиком и закладкой (CC-16).

## 4. Каталог наблюдений

Сборка: `VKM_RESOURCES_ROOT=<PRIVATE> python scripts/build_world_observations.py --runs high_full double --nav <NAV>`.
Выход — PRIVATE `WORLD_OBSERVATIONS/`: `world_observation_catalog.csv` (позиция = оцифрованная серия, просмотренный
рисунок, набор каталога мониторинга, оцифровка Мусихина или значение из текста), `digitized_series_points.csv`,
`digitized/` (на рисунок: серии, `calibration.json` с точками привязки осей и невязками, оверлей, скрипты).

- Площадка — строго по тексту и подписи; СКРУ-1 отмечен флагом `skru1_flag` (YES / SKRU1_OR_SKRU2 / NO).
- `available_from` — последний день года публикации источника (NAV `works_availability`): консервативная дата
  для правила `available_from ≤ t0`; эпохи измерений — отдельно.
- Оцифровка — всегда `DERIVATION`; число из текста — `PUBLISHED_VALUE`; ни то, ни другое не первичный журнал
  нивелирования. Модельные кривые и авторские прогнозы в каталог не входят.
- Оцифровано 09.10: Лебедева VKM-SRC-012 рис. 2.7–2.10, 4.8, 4.9, 4.12 (129 серий, линии 1/7/10 у целика
  СКРУ-1/СКРУ-2 — `SKRU1_OR_SKRU2_UNATTRIBUTED`, линии 2 и 8 — UNKNOWN); Ермашов VKM-SRC-045 рис. 4.3.3, 4.3.4,
  4.3.8–4.3.11 (СКРУ-2, линии № 2 и № 7); VKM-SRC-204 рис. 2 (БКПРУ-4, линия № 5); VKM-SRC-004 рис. 3, 8
  (PS-InSAR Березники).
- **Ряды СКРУ-1** (оцифровка 09.10, площадка — по тексту и подписи):
  - Кудряшов 2013 (VKM-SRC-011), рис. 4.7б: участок №1, блок 201, профильная линия 12, реперы 45–78, эпохи 1992,
    1995, 2004, 2007, 2010; максимум у Rp64 552 / 914 / 1019 / 1092 мм; ось разлома № 98 ≈ 150 м от максимума;
  - Соловьёв и др. 2019 (VKM-SRC-266), рис. 4.2: блок 199, реперы 13 и 25, оседание и скорость 1988–2009 (до
    3,3 м и ≈ 1016 мм/год в 1997 г.; подпись оси «м» противоречит аннотации — записано как конфликт, значения в мм);
  - VKM-SRC-266, рис. 4.3: 5 ВП, пласт В, реперы 101 и 114; время от неизвестного t0 (абсолютных дат нет);
  - Мусихин (VKM-SRC-002), слайд 14: InSAR-ряд 2011–2016 — СКРУ-1 или СКРУ-2 (заголовок слайда о двух рудниках).
  Ближайшие к СКРУ-1 прочие ряды — линии 1/7/10 Лебедевой у целика СКРУ-1/СКРУ-2 и линия № 7 Ермашова (СКРУ-2).

## 7. Добавлено 10.10.2026

- **Охват.** Миры — для всего ВКМ; целевые участки СКРУ-1, СКРУ-2, СКРУ-3, БКПРУ-4 (решение владельца). Черновик
  диапазонов (`scripts/build_world_priors.py`, `world_priors_proposal.csv`) предлагает C1 и C4 по каждому участку, C2 —
  по классу пород для ВКМ с числом значений каждого участка; где у участка своих данных нет — строка «данные других
  участков ВКМ» (ANALOGUE_VIA_TRANSFER).
- **Разбор записей** (PRIVATE `WORLD_EXTRACTION/adjudication/`): вердикты CORRECT / CORRECTED / REJECT /
  NOT_WORLD_PARAMETER по изображению страницы, исправленные поля, класс породы, множитель шапки, ветка; последний файл
  по имени побеждает. Неправдоподобные числа отбираются `scripts/extract_plausibility_flags.py` (физические границы,
  ×10 от медианы группы, неприменённый множитель шапки), группы для разбора — `scripts/extract_review_groups.py`.
- **Рудник по документу** (`curated/source_site_ranges_20261010.csv`): если на странице рудника нет, берётся рудник
  главы/статьи (`site_basis = DOCUMENT_CONTEXT`); `content_kind = WORKED_EXAMPLE` исключает числа учебных примеров.
- **C1 — скважины.** Отбивки Phase 1 и отбивки разбора страниц (`curated/borehole_picks_*.csv`,
  `scripts/build_borehole_picks_review.py`) дают строки мощности, глубины и отметки кровли/подошвы по скважине и толще

- **C4 — календари и планы.** `curated/<рудник>_mining_calendar*.csv` (события как годы, план отдельно от факта, размеры

- **Публичная проекция.** Строки прогонов Sol — отдельными файлами по модулям (`passport_evidence_<модуль>_sol_<прогон>.csv`),
  каждый публичный файл < 5 МБ.
