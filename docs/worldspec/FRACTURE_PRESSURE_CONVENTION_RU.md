# Давление конечного контрольного объёма трещины

Модуль `vkm_world.representations.world0.fracture_control_volume` использует
массу в единицах опорного объёма: m=M/rho_ref−V_ref [m³].
Задана относительная свободная энергия

Psi(m,V) = K/(2V) * (m−V+V_ref)² [J].

Её переменные, сопряжённые массе и объёму, различны:

p = dPsi/dm = K*((m+V_ref)/V−1) [Pa],
Pi = −dPsi/dV|m = p+p²/(2K) [Pa].

`p` — приращение химического потенциала, умноженное на rho_ref.
Это массовый потенциал в единицах давления. Параметр метода
`pressure_increment_Pa` сохранён для совместимости вызовов и означает p.
`Pi` — приращение механического давления. Для полного потенциала
F(M,V)=Psi+mu_ref*M−P_ref*V получаем
mu=mu_ref+p/rho_ref и физическое давление P=P_ref+Pi.
Начальное внешнее обжатие уравновешивает P_ref; приращения механики
используют Pi. Это модельное уравнение состояния, не измерение свойств трещины.

Согласованные связи:

rho/rho_ref=1+p/K;
P−P_ref=(K/2)*((rho/rho_ref)²−1);
dPi/dp=1+p/K;
dm/dg=(1+p/K)*dV/dg;
dPsi=p*dm−Pi*dV.

Для баротропного звукового возмущения этой модели
c²=dP/drho=(K/rho_ref)*(1+p/K), а касательный объёмный модуль
rho*c²=K*(1+p/K)². K — модуль при опорной плотности.
Допуск abs(p)/K<=0.01 ограничивает относительное изменение плотности.
Порог кавитации проверяется по P_ref+Pi, без clipping.
Если порог достигнут, однофазная насыщенная модель прекращает приём состояния;
переход к газовой фазе этим модулем не реализуется.

Возвращаемые имена:

- `mass_potential_increment_Pa`: p;
- `mechanical_pressure_increment_Pa`: Pi;
- `absolute_mechanical_pressure_Pa`: P_ref+Pi;
- `pressure_conjugate_Pa`: прежний alias Pi;
- `absolute_pressure_Pa`: alias физического P_ref+Pi.

До исправления последнее поле и cavitation guard использовали P_ref+p.
Например, P_ref=2MPa,K=2.2GPa,p=−1997500Pa даёт прежнюю метку2500Pa,
но физическое P=3406.819602Pa; при пороге3000Pa состояние допустимо.
Исправление не меняет m, Psi, Pi, касательные или уравнения равновесия.
Оно меняет pressure reporting и исход domain check около порога.
Старые расчёты нужно сохранять с исходными labels; новое reporting не
означает незаметного пересчёта прежней траектории.

При соединении с каналом поток опорного объёма Q_ref=Mdot/rho_ref
сопряжён разности массовых потенциалов p. Замена этой разности на Pi
без изменения carrier equations нарушила бы энергетическое сопряжение.
Интерпретация constant-density pipe Q_ref как фактического объёмного потока
остаётся приближением в объявленном диапазоне изменения плотности.
Подключаемый adapter должен отдельно хранить p и физическое P; минимум
давлений при проверке кавитации собирается из физических давлений носителей.

Synthetic tests проверяют обе производные потенциала, производную P(rho),
ложное старое срабатывание и состояния с двух сторон физического порога.
Натурная калибровка, многофазность и пространственная акустика не заявляются.
