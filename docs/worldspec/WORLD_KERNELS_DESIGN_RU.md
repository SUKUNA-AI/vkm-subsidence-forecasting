# Миры и микроядра: проект v1 (Phase 2, решение D-19)

Цель — ансамбль физических миров СКРУ-1 (3D + время), согласованных с evidence корпуса. По ним:
- считаются оседания;
- строятся синтетические измерения;
- обучается и проверяется нейросеть прогноза оседаний (ядро спецчасти).

Решение пользователя — D-19 ([PHASE1_DESIGN_DECISIONS_RU.md](../governance/PHASE1_DESIGN_DECISIONS_RU.md)). План
по неделям — [PHASE2_PLAN_OCT_NOV_2026_RU.md](../planning/PHASE2_PLAN_OCT_NOV_2026_RU.md). Модель данных мира —
[WORLD_SPEC_VNEXT_RU.md](WORLD_SPEC_VNEXT_RU.md).

## 0. Правила, которые проект не нарушает

- Мир — **модель**. Его поля и синтетические измерения — MODEL/DERIVATION, никогда не наблюдения. Проверка на
  реальности — только по реальным наблюдениям корпуса в пределах их применимости.
- Каждый параметр мира имеет основание:
  - EVIDENCE — запись evidence с локатором, масштабом и областью;
  - SCENARIO — явно маркированный диапазон для UNKNOWN;
  - MODEL_CHOICE — выбор модели.

  UNKNOWN не заменяется правдоподобным числом. LAB ≠ MASSIF; аналог ≠ СКРУ-1 — только через `Transfer`.
- Конфликтующие источники не усредняются: конфликт становится двумя сценариями.
- Бенчмарк нейросети предрегистрируется до обучения. Данные с `available_from > t0` в прогнозе в момент t0 не
  используются.

## 2. Понятия

- **Микроядро** — модуль, у которого описаны:
  - входы и выходы — поля с координатами (x, y, z, t), единицами и носителем (скаляр, профиль, сетка, ряд);
  - параметры с основаниями;
  - математика — ID моделей реестра и процессов PC;
  - уровень точности;
  - тесты: аналитические случаи, размерности, законы сохранения.
- **Мир** — экземпляр `WorldSpec`, выборка параметров, версии ядер и зёрна случайности. `world_id` — хеш их
  канонического JSON, так что мир воспроизводится бит в бит.
- **Уровни точности:**
  - L0 — аналитика и полуаналитика (быстро, тысячи миров);
  - L1 — МКЭ Ansys MAPDL (основной решатель, сотни миров);
  - L2 — OGS + MFront (проверка на 2–3 сценариях).
- **Сцепление** — ориентированный ацикличный граф ядер по слоям причинного графа. Обратные связи (закладка ↔
  конвергенция, ползучесть ↔ разгрузка) разрешаются внутри одного ядра или шагами по времени, а не циклами между
  ядрами.

## 4. Параметры: таблица оснований

Для каждого параметра ядра — одна строка:
- значение или диапазон и распределение;
- основание (EVIDENCE — ID записи и локатор; SCENARIO — метка сценария; MODEL_CHOICE);
- масштаб (LAB, MASSIF, UNSTATED) и перенос (`Transfer` для аналогов);
- область (SKRU1 или аналог);
- `available_from`.

Таблица собирается из evidence-каталогов и корпуса через навигационный слой: `find_formulas`, `explore_concept`,
`get_formula_context`, поиск. Параметры, которых нет в evidence, — сценарные диапазоны с меткой и причиной (ID из
`unknowns` WorldSpec). Конфликты источников (`physics_conflicts.csv`, `formula_conflicts.csv`) — отдельные сценарии,
не среднее.

## 5. Ансамбль миров

- **Выборка:** латинский гиперкуб или Соболь по пространству параметров, стратифицированный по дискретным сценариям
  (семейство закона ползучести, λ, эффективность закладки, схема выемки).
- **Объём:**
  - L0 — 5–20 тыс. миров;
  - L1 (Ansys) — 200–500 миров, отобранных для покрытия пространства;
  - L2 (OGS) — 2–3 сценария.
- **Многоуровневая точность:** модель расхождения L1 − L0 (или co-kriging) поправляет быстрые миры. Отложенные миры L1
  не участвуют в калибровке.
- **Хранение:** производные артефакты. Параметры и метаданные — Parquet; поля — Zarr (или NetCDF). У каждого прогона
  есть квитанция: вход, версии ядер, команда, лог, код выхода, проверка.

## 6. Нейросеть прогноза и бенчмарк

**Задача.** По наблюдениям до t0 (нивелирование по реперам, InSAR) и контексту горных работ предсказать оседания
на t0 + h в реперах и узлах сетки, с оценкой неопределённости.

**Модели:**
- базовые — продолжение по нормативной методике и подгонка функции времени по каждому реперу;
- рекуррентные и свёрточные по времени (GRU, TCN) с контекстом;
- пространственно-временные — граф по реперам или U-Net / нейро-оператор по сетке.

**Предрегистрация до обучения:**
- разбиение по мирам (train / val / test);
- разбиение по времени (срез t0);
- горизонты h;
- метрики: MAE и RMSE оседаний, ошибка максимума мульды, положение границы мульды, калибровка интервалов.

**Проверка на реальных наблюдениях корпуса:**
- InSAR Березников и Соликамска;
- опубликованные ряды нивелирования, оцифрованные с провенансом.

Реальные ряды не используются для подбора модели. Результат описывается как проверка переноса, а не как полевая
валидация сверх применимости.
