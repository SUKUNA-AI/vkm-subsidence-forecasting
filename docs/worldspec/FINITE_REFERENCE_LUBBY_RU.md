# Ограниченное конечнодеформационное семейство LUBBY-II

Модуль `vkm_world.representations.world0.finite_lubby` использует существующий
изотропный LUBBY-II с постоянным модулем Кельвина (`mG=0`) в фиксированном
материальном базисе. Это отдельный выбор физической модели. Он не является
автоматическим продолжением прежней малодеформационной истории рудника.

Состояние: время в секундах, деформация Грина `E=(FᵀF−I)/2`, второе напряжение
Пиолы `S` в Па, девиаторные памяти Кельвина `k` и Максвелла `v`. Шесть компонент
используют обозначения Манделя: `xx, yy, zz, √2xy, √2yz, √2xz`. Отсчётный объём
фиксирован. Для заданного постоянного смещения отсчёта `Eref` потенциал равен

```text
Ψ = ½ (E+Eref−k−v):C₀:(E+Eref−k−v) + G_K k:k,
P = F S,   σ = P Fᵀ / det(F).
```

Потенциал и диссипация имеют единицы Дж/м³ отсчётного объёма; модули — Па,
вязкости — Па·с, коэффициенты зависимости от эквивалентного `S` — 1/Па.
Свойства пород, термические связи и калибровку этот модуль не задаёт.

`finite_response` возвращает полный `dP/dF` с геометрической частью и допускает
только состояния с положительной достаточной точечной оценкой условия
Лежандра—Адамара для фактической алгоритмической касательной. Положительного
определителя `F` недостаточно. Отрицательная достаточная оценка означает
отсутствие данного допуска; она сама по себе не доказывает физическую потерю
устойчивости. `AdmittedTLModel` применяет тот же критерий в существующей малой
тетраэдральной сборке. Глобальная устойчивость и мелкая WEDGE-сборка этим не доказаны.

При положительном шаге, ненулевой памяти Кельвина, `mK≠0` и неразрешимо малом
девиаторном напряжении обычная производная не определена. Такой режим явно
отвергается до commit. Регуляризация и полугладкая постановка здесь не введены.
Мгновенный упругий шаг не использует производную вязкости. Неудачная проба
не заменяет принятое состояние и не обнуляет память.

`anchored_from_small` сохраняет напряжение, время, обе памяти и энергию
материальной точки при выборе нового отсчёта `F=I`. Он не переносит объёмы,
геометрию, граничную работу и порты старой сетки. Для связанной задачи необходимы
отдельные начальная постановка и проверка равновесия. Проверка работы ветвей
при удержанном втором напряжении Пиолы не заменяет глобальный энергетический
баланс событий выемки/закладки.

Синтетические регрессии `tests/world/test_finite_lubby.py` проверяют полную
касательную независимыми разностями по `F`, объективность, энергетический
баланс материальной точки, отказ при сильном сжатии, негладкую разгрузку и
сохранение памяти. Числа этих тестов не являются параметрами СКРУ-1.

Групповой WEDGE-адаптер и отдельное представление с неявной средней точкой
описаны в [REFERENCE_MIDPOINT_WEDGE_RU.md](REFERENCE_MIDPOINT_WEDGE_RU.md).
Они сохраняют физическую гипотезу; их собственные пространственные и временные
проверки не означают натурной валидации или замыкания событийной энергетики.
