# Поддержка исходных пикселей и безопасное упрощение полилиний

`vkm_geometry.native_pixel_support` — чистый Python-модуль без файлового ввода,
GIS/CAD, NumPy или сервисов. Его потребители — SOURCE QA исходных полилиний
(в том числе проверка рисунка 2.95) и подготовка производных представлений.
Он проверяет геометрию относительно **явно переданной маски**, не распознаёт
изолинии, подписи, штриховку, геологические контакты или связи между ними.
Подключение потребителя и научная приёмка выполняются отдельно.

```python
from vkm_geometry.native_pixel_support import validate_polyline, simplify_supported_path

frame = {
    'id': 'synthetic-pixels', 'width': 8, 'height': 4,
    'origin': 'top-left image edge', 'x_axis': 'right', 'y_axis': 'down',
    'unit': 'pixel', 'crs': None, 'registration_status': 'NOT_GEOREFERENCED',
    'pixel_centres': '(column+0.5,row+0.5)',
}
# Только синтетический пример. В рабочем вызове оба expected-поля берутся
# из независимо закреплённых метаданных проверенного входного изображения.
pins = dict(frame=frame, expected_frame=dict(frame),
            source_sha256='a3' * 32, expected_source_sha256='a3' * 32)
cells = [[x, 0] for x in range(5)]
path = [[.5, .5], [1.5, .5], [4.5, .5]]
proof = validate_polyline(path, cells, **pins)
assert proof['supported']
derived = simplify_supported_path(path, cells, tolerance=.1, **pins)
assert derived['path'] == [[.5, .5], [4.5, .5]]
assert derived['original_vertex_indices'] == [0, 2]
```

`support_cells` — конечная последовательность уникальных пар целых индексов
`[column,row]` в пределах кадра, максимум 100 000 ячеек. Последовательность
`blocked_cells` необязательна, но должна быть явным подмножеством исходной маски.
Блокирование исключает поддержку из проверки, сохраняя исходную маску в proof.
Пустая поддержка допустима и даёт `supported=False`.
`path` — непустая последовательность пар встроенных чисел `int`/`float`;
булевы значения, NaN и бесконечности не допускаются. Входы не изменяются.

Кадр требует все поля примера; размеры — положительные целые не больше
`2**31-1`. Другие JSON-метаданные сохраняются как непрозрачные данные: они
не интерпретируются как геодезическая регистрация или поля физического мира.
Известные поля EPSG и метрической калибровки не допускаются, включая
`meters_per_pixel`/`metres_per_pixel` и их варианты с дефисами.
Обе SHA-строки должны содержать ровно 64 шестнадцатеричных
символа и совпадать побайтно. Кадры сравниваются по каноническому JSON.
Эти guards проверяют согласованность закреплённых входов: модуль **не читает
изображение**, не подтверждает его SHA и не доказывает правильность маски.
Проверить байты источника, предикат маски и соответствие рамки обязан вызывающий код.

`validate_polyline` проверяет каждый **полный замкнутый сегмент** в точном
объединении замкнутых единичных ячеек `[x,x+1]×[y,y+1]`. Используются рациональные
числа (`Fraction`); нет дискретного семплирования, epsilon, расширения маски
или проверки только концов. Касание общей границы/угла допустимо. Одинокая
точка и нулевой сегмент проверяются как принадлежность ячейке. Это соглашение
о пиксельной поддержке, не доказательство физического соединения объектов.
Для замкнутой линии вызывающий код явно повторяет первую точку последней.

Результат содержит исходные координаты, frame/SHA, интервалы параметра `[0,1]`
по ячейкам и объединению, непокрытые интервалы и индексы сегментов. Рациональные
границы сериализуются как `{numerator, denominator}`. Производный кадр/EPSG,
высота или статус научного/человеческого подтверждения не назначаются.

`simplify_supported_path` применяет Рамер–Дуглас–Пекер (RDP) с расстоянием
**до конечного отрезка**, а не бесконечной прямой. Хорда сохраняется лишь когда
все исходные вершины её подцепочки в пределах `tolerance` и **вся хорда**
покрыта исходной эффективной маской. Допуск измеряется в пикселях и не расширяет
поддержку. Выход — только подмножество исходных вершин с их индексами;
обратный ход за конец хорды учитывается. Новые координаты и соединения через
белые разрывы не создаются. Координаты и порядок оригинала доступны отдельно.

При неподдержанном оригинале функция возвращает его без ремонта и статус
`ORIGINAL_PATH_UNSUPPORTED`. При нулевом допуске сохраняются все вершины.
Замкнутые пути сохраняются с явным статусом
`REJECTED_CLOSED_LOOP_TOPOLOGY_PRESERVED`: их упрощение этим API не выполняется.
Общая топология открытых сетей, взаимные пересечения разных линий, сохранение
длины/параметризации и семантика не гарантируются. `supported=True` означает
поддержку геометрии объявленной маской, не полноту карты или SOURCE admission.

Стоимость proof пропорциональна числу проверяемых сегментов × числу ячеек;
RDP также имеет квадратичный худший случай по вершинам. Используйте ограниченные
ROI и сохраняйте исходные пути, proof, версию кода и отдельное решение SOURCE QA.
Автоматическая трассировка, скелетизация и семантический выбор ветвей сюда не входят.
