# Кандидатное пересечение штрихов и рамок подписей

`vkm_geometry.association.associate(payload)` проверяет пересечение **реальных
невыражденных отрезков** переданных полилиний с замкнутой прямоугольной рамкой
подписи (ROI). Касание границы учитывается. Все допустимые совпадения сохраняются;
ближайшая линия, продолжение через пробел и принадлежность изолинии не выбираются.

Контракт входа: `frame={id,unit:"pixel",source_sha:64hex,crs:null}`,
`complete_pool:bool`, `labels=[{id,frame_id,source_sha,roi:[x0,y0,x1,y1],scalar}]`,
`fragments=[{id,frame_id,source_sha,role,points:[[x,y],...]}]`.
Ключи точные; дополнительные или отсутствующие поля вызывают `ValueError`.
Координаты — конечные `int/float`, без `bool`; целые не преобразуются во float.
ROI имеет положительную площадь; полилиния содержит хотя бы один ненулевой отрезок.
IDs уникальны отдельно внутри списка подписей и списка фрагментов.
Рамка и SHA каждого объекта точно совпадают с общими; регистр SHA допустим любой,
но сравнение внутри пакета чувствительно к регистру. Вход не изменяется.

Роли: только `candidate`, `annotation`, `unqualified`; участвует лишь `candidate`.
Выход — `labels`, отсортированный по ID, с полями `id,status,candidates,
label_scalar,height_assignment,pool_complete`. Кандидаты отсортированы.
`NO_EVIDENCE` означает отсутствие пересечений **в переданном наборе**.
`CANDIDATE` возможен лишь при одном пересечении и `complete_pool=true`;
иначе непустой результат — `AMBIGUOUS`, в том числе единственный при неполном пуле.
`height_assignment` всегда `null`; известное значение или `null` в `scalar`
сохраняется лишь как аннотация подписи. Статусы не доказывают владельца линии,
полноту извлечения, систему высот, геопривязку или научную достоверность.

Арифметика пересечений использует точные `Fraction` для представленных чисел.
Это не метрологическая точность исходного изображения и не обещание ограниченного
времени исполнения для целых произвольного размера. Тесты используют только
синтетические координаты: независимый ориентационный эталон, границы, пробелы,
роли, метаморфные преобразования, крайние конечные числа и отказы входного контракта.

После интеграции в пакет: `python -m unittest discover -s tests/geometry -p test_association.py`.
Нужна только стандартная библиотека Python; исходные изображения/данные не нужны.
