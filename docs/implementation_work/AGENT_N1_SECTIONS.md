## 1. Как строится дерево

Один метод на источник, по приоритету; первый давший пригодное дерево побеждает:

1. **Закладки** (`PDF_OUTLINE` / `EPUB_NAV` / `DJVU_OUTLINE`) после фильтра мусора: ≥ 10 закладок на ≤ 2 или < 10 %
   различных страниц; закладок больше 3× страниц; одна закладка уровня 1 на каждую страницу; больше половины заглавий —
   имена файлов или «стр001»; меньше двух пригодных закладок.
2. **Печатное оглавление** (`PRINTED_TOC`): строки блоков `TABLE_OF_CONTENTS` → (нумерация, заглавие, печатная
   страница). Склейка переносов, нумерация на отдельной строке, номер страницы отдельной строкой, отточия, «•»,
   колоночная вёрстка (номера страниц отдельным блоком). Печатная страница → физическая: прямая метка
   (`CONSISTENT_SEQUENCE`) → доминирующее смещение меток → доминирующее смещение заглавий, найденных среди заголовков.
   Неотображаемая страница отбрасывается, не угадывается. Запись сдвигается к своему заголовку не дальше ±2 страниц.
   Оглавление, у которого < 40 % записей нашли заголовок на своей странице, уступает следующему методу.
3. **Нумерованные заголовки** (`HEADING_NUMBERING`): «Глава 3», «ЧАСТЬ II», «3.2.1», «§ 5», «Chapter 3», «I.».
   Каждое семейство нумерации (главы, §, n.m, римские) должно расти само по себе; выбросы отбрасываются. Ключевые
   заголовки («Введение», «Заключение», «Список литературы», References…) — верхний уровень. Для выпусков журналов и
   сборников метод пропускается: нумерация перезапускается в каждой статье.
4. **Заголовки разметки** (`HEADING_LAYOUT`): блоки `TITLE` одной страницы склеиваются и дают уровень 1 (статья,
   глава); `HEADING` — уровни ниже. Шум (УДК, DOI, ©, < 2 букв) и колонтитулы, повторённые на ≥ 4 страницах,
   отбрасываются.
5. **`WHOLE_SOURCE`** — один раздел на весь источник, если структуры нет (заглавие — блок `TITLE` страниц 1–2, иначе
   заглавие Work). В дизайне этого значения `method` нет — **добавлено**, см. §4.

Уровни — из уровня закладки или ранга нумерации (часть 0, глава 1, n.m — по глубине), затем нормализуются в глубину
дерева. Раздел длится до начала следующего раздела того же или более высокого уровня (его страница минус 1); родитель
покрывает страницы детей. Начальные страницы в порядке чтения не убывают (наибольшая неубывающая
подпоследовательность). `confidence` = база метода (закладки 0,85–0,9; оглавление 0,7; нумерация 0,6; разметка 0,4;
целиком 0,5) + 0,1 за каждый другой метод с тем же заглавием в пределах ±1 страницы + 0,05 за найденный блок
заголовка − 0,1 за страницу по смещению заголовков или по следующей записи. `heading_block_id` — блок `HEADING`/`TITLE`
(или короткий `TEXT`/`PAGE_HEADER`) стартовой страницы с похожим заглавием (≥ 0,8).

Поля `sections` — как в дизайне, плюс `page_start_index` / `page_end_index` (физические номера для соединений по
диапазону). `section_pages` — для каждой покрытой страницы самый глубокий раздел (или два соседних, если второй
начинается на странице, где начался подраздел первого), плюс `source_id`, `page_index`, `rule_version`.

## 4. Открытые вопросы

- **`WHOLE_SOURCE`** — новое значение `method` (8 источников без структуры). Координатору: внести в список методов
  дизайна или заменить на `HEADING_LAYOUT`.
- Дополнительные колонки `page_start_index`, `page_end_index` в `sections`; `source_id`, `page_index`, `rule_version`
  в `section_pages`.
- Строгий приоритет: грубые закладки побеждают подробное оглавление (VKM-SRC-029: 9 закладок против оглавления на
  3 страницах). Слияние методов (закладки сверху, оглавление/нумерация внутри) — следующий шаг.
- Плоские деревья там, где части не попали в оглавление и § перезапускается (VKM-SRC-230); заглавия оглавления
  выпусков журналов содержат авторов и рубрики, как напечатано; OCR-шум в заглавиях сохраняется как напечатан.
- Заголовки разметки (126 источников, в основном статьи) — уровень по типу блока, без размера шрифта; в больших книгах
  без оглавления дерево может быть плоским.
- Агрегаты раздела из дизайна (`key_terms`, `central_passages`, вектор раздела) не строились: они требуют векторов и
  TF-IDF по корпусу (координатор / N3). Счётчики рисунков, таблиц, формул и литературы считает `get_section`.
- `test_public_hygiene.py` в WSL не запускается для этого worktree (git в WSL не читает ссылку worktree Windows);
  на Windows — 6 passed.
