# Диплом и геологическая основа СКРУ-1 · R3

Текущая авторская сборка находится в PRIVATE: `12_work_exports/skru1_diploma_current/`. Это рабочий диплом до специальной части. Полная приёмка не достигнута: отсутствует местная метрическая основа GD-01; две источниковые зарисовки сохраняют допущение о вертикальной калибровке. Предыдущие V2/R11 не служат авторскими мастерами.

## Фактические изменения

- Собственные вертикальные ссылки считаются по владельцу и идентификаторам; краткие метки прямых, условных и смешанных входов выводятся из скомпилированных операторов.
- Критерий выбора назван ближайшей к покомпонентной медиане конфигурацией. Детерминированный порядок выбора задан до выполнения. Старое название медоида не используется для иного расчёта.
- Идентичность поля связывает рамки, контактные пары и семантику материалов. Reader отклоняет пересохранённые, но семантически несогласованные queries/profiles/field.
- Геологические интервалы привязаны к паре верхнего и нижнего контактов. Подстилающая соль и маркирующая глина не получают свойства друг друга по порядковому номеру.
- Исторические локальные записи перенесены в общие каталоги без утраты ID, UNKNOWN, дат, цитат и независимости. Отдельный локальный сборщик и его лишние проекции удалены.
- Текущий мониторинговый builder читает закреплённые текущие таблицы, не извлекает данные через старый Git commit. Исторические проверки выполняются явно; отсутствие исполнения отражается как NOT_RUN.
- Хеш зарегистрированной публикации отделён от хеша производной таблицы. Разрешение идентичности использует явное пространство имён и проверяемые aliases, без неявного соединения по похожему ID.

## Предел результата

Новое C1 — условная пространственная интерпретация. Неизвестная связь высот не становится геодезическим преобразованием. Проверка численной геометрии и сеток не подтверждает точность тонких продуктивных слоёв. Новое поле не означает пересчёта физических историй, назначения C2 или натурной валидации. Старые расчёты сохраняют собственные входы и область применимости.

Текущие кодовые, межрепозиторные и источниковые проверки выполняются отдельно от научного допуска. Полный локальный CPU workflow сохраняет инфраструктурный отказ Windows при создании symlink; корпусный workflow не пройден из-за отсутствующих зависимостей. Непройденные проверки не названы успешными. PRIVATE оригиналы, геометрия, иллюстрации и авторский титул не публикуются в PUBLIC.
