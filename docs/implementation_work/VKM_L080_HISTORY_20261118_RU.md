# ВКМ / СКРУ-1. Исторический расчёт L080, волны 10–17

На представлении L080 с шагом 25 м выполнена условная связанная траектория с 1933 года до POST 1962,5. Из состояния 1941,5 продолжение включает 84 шага по 0,25 года и семь мгновенных переходов. На каждом переходе память реологии Максвелла побитово совпала между PRE и POST. Для последнего отрезка максимум инженерной деформации составил 4,6588% при пороге 5%.

Начальная предыстория задана сценарием. Старые точки WEDGE6 и среднее значение не определяют поле памяти однозначно. Для L080 выполнено повторное интегрирование истории. Модуль [maxwell_coefficients.py](../../src/vkm_world/representations/world0/maxwell_coefficients.py) сохраняет память через коэффициенты исходного базиса. Численный результат получен на коде `e4ede1c9f1ba1581d299258ab2e65c4b437db826`.
