# Локальный выпуск блока 201 от 30.10.2026

Выпуск выполняет ограниченную часть VKM-ENG-SPEC-001. Кодовые проверки, исследовательская геология,
академическая редакция, механический эксперимент и проверка прогноза имеют отдельные статусы.
Полные входы, реальные результаты, локальная модель, графика и ВКР находятся в PRIVATE
`12_work_exports/block201_release_20261030/`. Текущие совместимые версии и ограничения задаёт его
`release_manifest.json`; исторические receipts не переписываются.

## Изменения кода

- R3-05 / W0-001–002: взаимность податливости проверяется в метрике площадей портов;
  K и G используют одну принятую податливость. Неизвестные площади не выводятся из матрицы.
  Прежний вызов без площадей явно означает равноплощадный контракт.
- R3-06 / W0-003: критерий M-матрицы работает с общим несимметричным случаем.
  Численно неразрешённый знак не доказывает кооперативность.
- R3-07 / VAL-003: общие CV-оценки пересекают точные ключи эксперимента, fold, удержанной группы,
  физического объекта и контакта; разные контакты одной скважины не образуют общую пару.
- SUR-003: `withdraw_absolute_anchors` снимает абсолютную привязку выбранных скважин,
  сохраняя точные разности глубин отдельными ограничениями мощности. Исходник не изменяется;
  неопределённая абсолютная степень свободы не заменяется нулём.
- ENS-002/007: независимые малые проверки условной ковариации, соседних разностей,
  линейных функционалов и разбиения на чанки относятся к реальному grid sampler.
  Одномерный CV sampler сохраняет свою ограниченную роль.
- ENS-004: неудачный Холецкий при нулевом jitter завершается явным отказом;
  положительные повторы ограничены и протоколируются.
- ADM-001: допустимость проверяется по всему представленному миру, а не только долей нарушенных точек.
  Экспорт поднабора сохраняет координаты, связность и ID реализаций; механический допуск отдельный.

## Воспроизведение

После получения обоих репозиториев и LFS-полезной нагрузки PRIVATE:

```powershell
python -m pytest -q tests/world
python -m pytest -q tests/corpus/test_public_hygiene.py
python scripts/verify_canonical_repository.py --output work/release_verify.json
& "$env:VKM_RESOURCES_ROOT/12_work_exports/block201_release_20261030/reproduce.ps1" -PublicRoot . -ResourcesRoot $env:VKM_RESOURCES_ROOT
```

`VKM_RESOURCES_ROOT` должен указывать на PRIVATE. На Windows без права создания символьных ссылок
один защитный тест пути требует WSL; его не отключают и не заменяют формальным PASS.

`scripts/assess_site_geology.py` выполняет парные проверки через производственный ContactPredictor;
выборка и позиционная классификация фиксированы по общему baseline. Он сохраняет сырые остатки,
точные ключи, ошибки отметок и мощностей, входные хеши и выбранную трассу.
`scripts/compare_surface_products.py` сравнивает поверхности на общих диагностических точках,
разделяя маски, высотные системы и альтернативные scale-операции.
`scripts/export_site_bundle_gpkg.py` запускается в существующем Python QGIS/GDAL и проверяет обратное чтение
координат, связности и числа записей; EPSG локальной системе не назначается.

## Ограничения

Согласованность кода и геометрии не является полевой валидацией. Исторический datum,
подтверждённая хронология под наблюдательной линией, продуктивные пласты и материальное состояние
проверяются отдельно. До соответствующих ворот ансамбль не используется как вход механики.
Новый расчёт всего поля, обучение ML и оценённый прогноз этим выпуском не заявляются.
Оригинальная матрица спроектированных проверок не считается журналом выполненных тестов.
