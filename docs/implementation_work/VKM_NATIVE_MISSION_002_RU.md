# VKM-NATIVE-MISSION-002. Связанная механика КрII

В вычислительной постановке каждый участок пласта имеет одну степень свободы — осевое сближение. Разность сближений нагружает пружину на общей грани, а парные усилия входят в единое уравнение равновесия. Приложенная нагрузка выводится из веса вышележащих толщ. Она фиксирована в рамках сценария.

Событие выемки уменьшает несущую площадь. Память линейного закона Максвелла сохраняется в оставшейся части. Закладка получает собственную опорную конфигурацию при рождении и передаёт сжимающее усилие после закрытия зазора. Временной шаг заканчивается точно на событии. При отклонении шага пробная память отбрасывается.

## Воспроизведение

Из корня PUBLIC установите зависимости проекта и задайте `VKM_RESOURCES_ROOT` для доступа к закрытым исходным данным. Исполнимый вход `vkm.world0.joint/1` формируется в закрытой поставке. Она содержит правила подготовки, источники, интерфейсы и сценарные интервалы. Перед проектным расчётом выполните приложенную проверку оператора для тех же байтов входа. Она пересчитывает нагрузку, жёсткости и геометрию граней из закреплённых исходных данных.

```powershell
python src/vkm_world/representations/world0/joint.py $world $trajectory --checkpoint $checkpoint
python -m pytest -q tests/world/test_world0_joint.py
```

Пути входа и новых выходов задайте в переменных `$world`, `$trajectory` и `$checkpoint`. Для остановки сразу после события задайте `--stop-after-event N`. Для продолжения передайте исходный мир и `--restart $checkpoint`. Смена входного файла делает контрольную точку неприменимой. Выходной JSON содержит снимки с усилиями, памятью, остатком равновесия и работой события. Для сопоставления используйте одинаковые идентификаторы мира, представления и хеш входа.

MATLAB-реализация лежит в `scripts/world0/matlab_joint`. Передайте `run_l3` JSON-манифест с `world_paths` и при необходимости путь к независимой Python-траектории. Члены пакета используют общие идентификаторы узлов и набор рёбер. Они могут различаться законами в поддерживаемом линейном классе, жёсткостями и расписаниями. Используйте новый рабочий каталог и общий GPU-замок проекта. Для проверки сохранённого MAT-файла запустите `reopen_l3`.

## Проверенная область

- Скалярный связанный сценарий охватывает весь контур принятой геологии, с активной механикой КрII. Истории частичны и включают явно обозначенные гипотезы.
- Для этого сценария выполнены баланс, перезапуск, уменьшение шага и адресная проверка сетки в режиме без событий. Проверка внешней опоры относится к одному сценарию граничной жёсткости.
- В Ansys выполнен стадийный контроль двух участков. OGS/MFront отдельно проверил согласованный одноосный закон и касательный отклик образца. Нативные продукты QGIS, ParaView и Civil 3D сохраняются в закрытой поставке.
- Совпадение вычислений на CPU и GPU проверено в FP64. Чувствительность FP32 около порога контакта ограничивает его применение.
- Сближение пласта нельзя переводить в оседание поверхности без оператора распространения деформаций через покрывающие толщи. Активные векторные и межпластовые связи и детализация камер требуют отдельных проверок.
