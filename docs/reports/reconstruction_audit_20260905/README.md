# Доказательства аудита родительской версии

Это сохранённые результаты проверки commit `2c5eec48d523cf3fbc15898b0b44ac929b9b7c14`, а не новые результаты обучения после исправлений.

- `audit_summary.json`: инвентарь, нарушения статусов, повторно рассчитанные метрики сохранённых предсказаний B6/C1 и среда аудита.
- `membership_mismatches.csv`: 18 противоречий старого участия кампаний и принятых результатов уравнивания.
- `reconstruction_audit.json`: результаты независимого чтения иллюстраций и пределы реконструкции.
- `conformal_counterexamples.json`: малые контрпримеры правил выбора калибровочного квантиля.
- `evidence_manifest.json`: хеши этих четырёх файлов.

Реальные даты доступности источников не устанавливаются из общего 2022/2023 года. Счётчики origins раньше этих лет характеризуют прежнюю разметку, а не доказывают сами по себе причинный вклад пространственных полей в ошибку B7.

Исправленный выпуск и его проверки находятся в `data/reconstruction_research_v1/`; дальнейшие задачи — в `docs/governance/RESEARCH_DIRECTION_RU.md`.
