# Запрос данных научному руководителю

Дата: 29.09.2026. Студент: автор дипломной работы «Горные и маркшейдерские работы при разработке Верхнекамского
месторождения». Специальная часть — «Алгоритм прогнозирования оседаний земной поверхности на ВКМ на основе
маркшейдерских измерений».

## Зачем

Алгоритм прогноза собран на опубликованных данных. Корпус — 251 источник, база знаний с поиском, формулами,
параметрами и досье тем. Проверить прогноз на самом руднике СКРУ-1 мешает одно ограничение: нет пространственно-временных
данных рудника. Нужно знать, где и когда отрабатывались и закладывались камеры и как на это отвечала поверхность.
Даже частичные данные по одной-двум наблюдательным линиям позволят сравнить «прогноз с фактом».

Нужны и свежие наблюдения. Прогноз проверяется «вперёд»: он строится по данным до выбранной даты и сравнивается с тем,
что наблюдали после неё. Чем свежее ряд, тем длиннее проверка. Последнее состояние мульды — стартовая точка прогноза
на будущее.

Часть нужного уже собрана в ГИС-проекте рудника СКРУ-1: на нём сделаны ВКР Филатовой (НИТУ МИСИС) и две статьи
ГЦ РАН и ГИ УрО РАН (раздел «Где часть данных уже собрана»).
