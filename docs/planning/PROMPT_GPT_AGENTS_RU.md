# Действующий маршрут ВКМ / СКРУ-1

Задание R3 владельца от 24.11.2026 определяет диплом до специальной части, геологию всего шахтного поля СКРУ-1 и устранение подтверждённого легаси. Сначала завершается геологическая глава по оригиналу Щёкиной № 4574. Графика содержит 2 плана, 3 общих и 4 детальных разреза, 2 сводные инженерно-геологические колонки.

Начните с [правил](../../AGENTS.md), [состояния](../../PROJECT_STATE_RU.md), PRIVATE AGENTS и актуальных индексов источников. Установите checkout, SHA, рабочие изменения, входные версии и область текущей приёмки. Используйте уже проверенные источники и инструменты. Исходный участок выбирается по предметным основаниям, общего локального default нет.

Новые платные исследования, production, ML и полномасштабная физическая история этой задачей не разрешены. Научные состояния 2026 года сохраняют собственные временные границы и ограничения. Разделять их с приёмкой диплома.

При cleanup сначала установить потребителей и перенести уникальные необходимые сведения, затем удалить ненужные реализации. Проверять ссылки, проекции, происхождение данных, actual native CAD/GIS/Word и независимые регрессии. Технический PASS не является научным допуском или человеческим рецензированием.
