## 3. Запросы данных (отправить на неделе 29.09)

По §9 handoff. Главный для спецчасти — **№ 6: цифровые ряды нивелирования профильных линий СКРУ-1 с классом точности
и нулевой эпохой**. Без него алгоритм можно показать только на рядах, оцифрованных из публикаций корпуса, и на InSAR.
Следом по важности:
- № 1 — система координат и высот, переход к МСК-59 / ГСК-2011;
- № 5 — хронология выемки и закладки по блокам;
- № 2 — координаты скважин.

## 4. Решения, нужные от пользователя

- **Роли решателей** (D-18: OGS + MFront — основная ветка, Ansys — сверка). Предложение координатора при двухмесячном
  сроке: Ansys — основной инструмент расчётов, OGS — сверка на 1–2 сценариях. Любой результат решателя остаётся
  модельным, а не наблюдением.
- Состав сценариев геомеханики (2–3) и горизонты прогноза бенчмарка.
- Что входит в графическую часть диплома (листы).
