# Проектные решения Phase 1 (журнал)

Решения приняты координатором cloud-run по умолчанию, чтобы не блокировать работу. Каждое можно
пересмотреть: для этого решение записывается здесь заново с новым номером, старое не удаляется.

| ID | Вопрос | Решение | Обоснование |
|---|---|---|---|
| D-01 | Как отображать откалиброванные (back-analysis) значения старого релиза (109 записей CALIBRATED)? | `status = DERIVATION`, `evidence_type = MODEL_CALIBRATED`, `scale = CALIBRATED_EFFECTIVE_MODEL`, `method` = «обратный анализ автора, модель-специфично». Использовать как свойство массива (`MASSIF`) можно только через явный `Transfer` | Эффективный модуль, подобранный под конкретную МКЭ-модель автора, — производная величина этой модели, а не измеренное свойство. Проверяет `check_scale_use`; так сохраняются правила V18/V25 старого валидатора |
| D-02 | Статус учебных примеров (64 записи TEACHING_EXAMPLE)? | `status = ANALOGUE`, `scope = GENERAL_METHOD`, `evidence_type = TEACHING_EXAMPLE`. В WorldSpec как факт о СКРУ-1 **запрещены**: `MiningObject(TEACHING)` не может быть FACT; FACT+TEACHING_EXAMPLE запрещён валидатором | Числа индивидуальных заданий иллюстрируют метод, а не описывают объект |
| D-03 | `available_from` для значений из литературы | По умолчанию — дата публикации (точность «год»; при проверке доступности год разворачивается к 31.12, см. D-16), с пометкой `ASSUMED_FROM_PUBLICATION`. Для внутренних данных предприятия (маркшейдерские съёмки, журналы закладки) доступность **UNKNOWN**, пока нет свидетельства | Для прогнозиста в момент t0 опубликованное знание консервативно доступно не раньше публикации |
| D-04 | Коэффициент бокового распора λ/K0 | Хранится как `DISCRETE_SET` гипотез с источниками: 0.6 (БКПРУ-2, собственные измерения Бельтюкова), 0.71 (цитата Токсаров–Асанов, допущения σv = γH, σ2 = σ3), ≈1.0 (литостатическая гипотеза для солей; Гремячинское 0.9–1.0 — NON_VKM). Не усредняется | Конфликт гипотез, а не шум измерения |
| D-05 | Скважина 75 | Обычное наблюдение (EV-GEO-0202, табл. 3.1 Лебедевой). Решение RD-021 (выбор «репрезентативной» скважины) отозвано; представительная скважина не выбирается | Правило выбора было неустойчиво (медоид — скв. 23), а одна скважина ≠ месторождение |
| D-06 | Старый evidence-релиз `physical_evidence_v1` | Сохраняется как есть (классифицирован аудитом); связывается с vNext через таблицу отображения, не переписывается | История провенанса и воспроизводимость прошлых решений |
| D-07 | Оцифровка Мусихина (VKM-SRC-002, стр. 15) | Переходит в наблюдательный evidence со статусом **discovery-only**: FACT (оцифровка графика) с ограничениями; интервальные смещения, не временной ряд; рудник (СКРУ-1/СКРУ-2) не доказан. CSV → PUBLIC `evidence/monitoring/`, растры → PRIVATE | Единственные численные наблюдения оседаний в публичном дереве; нельзя выдавать за ряды СКРУ-1 |
| D-08 | Окончания строк в PRIVATE | Добавить `* -text` в начало `.gitattributes` (побайтовый checkout) | Иначе на Windows-клоне (autocrlf) ломаются ~1400 хешей (RPR-002) |
| D-09 | Frozen-ссылки PUBLIC | Проверяются по git-объектам (`legacy`, `ce8e57e`, `71d705d`, `ffcf869`, `10452b0`, `2794c87`, `c5da110`). Теги созданы локально; push тегов из cloud отклонён (403) и выполняется с workstation | Защита от сдвига веток; проверка без LFS и checkout |
| D-10 | LFS из cloud | Cloud-сессии не индексируют файлы, подпадающие под LFS-паттерны. Бинарники коммитятся только с workstation | `lfs.github.com` → 403; иначе push ломается или публикует pointer без объекта |
| D-11 | Пропавшие пачки sweep (коллизия скриптов) | После sweep сравнить `pages_done` с фактическими записями. Страницы с высокой плотностью доменных терминов без записей перечитать адресно | Защита от «тихой» потери при коллизии scratch-файлов |
| D-12 | Внешний поиск при закрытой сети (Firecrawl 402, egress-политика закрывает научные домены) | Продолжать только через WebSearch. Уровень доступа указывать честно: METADATA_ONLY / ABSTRACT_ONLY, а FULL_TEXT_READ — только при фактическом чтении полного текста. Утверждения из машинной сводки поисковика — «наводка» с confidence LOW. Недоступные первоисточники передаются в Phase 2 | Иначе метаданные и пересказы поисковика выдавались бы за прочитанные первоисточники |
| D-13 | Поправки визуальной OCR-QA (`evidence_corrections.csv`, статус PROPOSED) | Не переписывать записи sweep и канонические каталоги. Поправки публикуются как оверлей вместе с таблицей влияния «поправка → каталог → строка». Сборщик мира в Phase 2 (P2-01) применяет их явно и пишет receipt | Первичная запись чтения остаётся неизменной; каждое применение поправки трассируемо |
| D-14 | Исправление находок критической самопроверки | Системную ошибку исправлять в сборщике потока, пересобирать каталог и проверять, что diff затрагивает только нужные строки. Точечную ошибку — через таблицу правок `review_fixes.csv` (каталог, строка, колонка, старое → новое, id находки); скрипт применения сверяет старое значение. Каждая правка ссылается на находку | Корень ошибки устраняется; правки воспроизводимы и не «теряются» при пересборке |
| D-15 | Корни инструментов run kit | Сырые выходы sweep по умолчанию берутся из закоммиченной копии PRIVATE `11_evidence_vnext/sweep_raw`. Объединённые выходы пишутся в `$VKM_WORK/merged` (переопределяются `VKM_SWEEP_DIR`, `VKM_MERGED_DIR`, `VKM_SYNTH_DIR`) | Пересборка работает из git без рабочего каталога cloud VM; проверено побайтово |
| D-16 | Точность дат и доступность физических событий (находки CHRONOLOGY-014/023) | Даты сравниваются как интервалы по `precision`. `usable_at` использует самый поздний возможный день `available_from`. Физическое событие известно на t0 только через собственную `available_from` или информационное событие из `revealed_by` (`known_physical_at`); неизвестная доступность — не используется | Иначе годовая дата публикации делает знание «доступным» до выхода книги, а мир на t0 включает события, о которых прогнозист не знал |
| D-17 | Разделение области SKRU1_SKRU2 (находки ATTRIBUTION-006/007, TRANSFER-023) | Новые значения: SKRU1_SKRU2_PILLAR (зона целика), SKRU1_OR_SKRU2_UNATTRIBUTED, SOLIKAMSK_GROUP. Как СКРУ-1 без `Transfer` засчитывается только SKRU1 (зона целика — при локальном использовании). SKRU1_SKRU2 остаётся допустимой устаревшей меткой, но значением СКРУ-1 не считается. Масштаб по умолчанию — UNSTATED; параметр материала обязан указать масштаб | Одна метка обозначала четыре разных ситуации, и страж пропускал все четыре как данные СКРУ-1 |
