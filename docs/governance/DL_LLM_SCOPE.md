# DL, Foundation Model and LLM Scope

## Source-derived part

The predecessor SKRU-1 thesis explicitly required neural and neuro-fuzzy methods and compared ENFS, a classical neural network, random forest and gradient boosting. Expanding the architecture comparison is therefore justified.

## Project extension

LSTM, TCN, transformers, graph neural networks and time-series foundation models are a new project extension. They are not claimed to be present in the source production dataset or to have been validated on real SKRU-1 cycles.

## LLM distinction

A language model is not the same as a time-series foundation model. For numeric forecasting, the project prioritises models trained for continuous temporal data. A general LLM is restricted to source-grounded reasoning, tool orchestration, metadata extraction and explanation.
