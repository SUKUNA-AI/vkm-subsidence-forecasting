# Независимые синтетические проверки R1

Из этого каталога выполнить `python -X utf8 check_surface.py`. Проверены Python 3.13, NumPy 2.4 и Matplotlib 3.10 на CPU. Точные рациональные вычисления используют стандартный модуль fractions. Команда возвращает ненулевой код, если хотя бы одно сравнение выходит за допуск, и записывает [результаты](RESULTS.json) и [рисунок](SYNTHETIC_R1.png). Входы заданы в скрипте; внешние сервисы и полевые данные для воспроизведения не нужны. Размерные единицы примеров — м, год, для компонент напряжения и энергии на единицу объёма допускается нормировка на 1 Па. Цифры, полученные в такой нормировке, не являются свойствами массива.

| C03 | Два корня ±√u формы четвёртой степени при u=1/4, плоская вершина при u=0, квадратичный пик вне полуоси и две конкурирующие ветви | У ветвей максимума односторонние скорости −1 и +1. Вырождение и граница исключают безусловное применение формул с обратным гессианом |

| C05 | Горизонтальный шаг 1 м, СКО отсчёта 0,1 м. Квадратичный профиль с добавкой 0,04x⁴ в заданных единицах. На площадке также 0,3xy−y². Индивидуальные ошибки либо независимы, либо имеют ковариацию σ²ρᵈ при ρ=0,65 и манхэттенском расстоянии d в шагах сетки | Для уровня, уклона и Hxx рассчитаны смещение, СКО и полная среднеквадратическая ошибка. Использованы аналитические моменты без случайной выборки. Дисперсии сверены через разложение Холецкого, а для второй разности — ещё с формулой по трём лагам |

| C10 | Положительные веса мягкого максимума; k=4 м⁻¹ и R=1 м; две маски; круговой уровень у гауссиана с растущей амплитудой | Численное интегрирование даёт коэффициент передачи 0,2799233. Подтверждены направление оценки максимума и скорость изменения площади 2π м²/год. Смена весов создаёт ложное изменение 0,25 м |

Все допуски находятся в вызовах сравнения. Для точных рациональных равенств после проверки в узлах используется нулевой допуск на одинаковые представимые выходы. Для линейной алгебры принят абсолютный допуск 2·10⁻¹², для симметричной разности и восстанавливаемых параметров — явно заданный допуск с учётом шага. Число скалярных и векторных сравнений имеет технический смысл. Неразрешимость ориентации круга, момента события внутри окна, направления слабого сигнала и поперечного гессиана зафиксирована как ожидаемый отрицательный научный результат.

| Линия, независимые | 0,25768 | 0,35830 |

При расширении окна полиномиальной оценки случайная ошибка падает, а смещение от члена четвёртой степени возрастает до 0,35429 м⁻¹. Это объясняет, почему более гладкая оценка на рисунке имеет меньшую СКО и большую полную ошибку.
