# T02 — Операторная механика, память, микроядра
v0.3-draft, 26.11.2026. TEST_REQUIRED; конкретные известные тождества отделены от применимости к ВКМ.

## 1. Редукция и интерфейсы
Microkernel — редуцированная подсистема, response kernel — оператор отклика, memory kernel — наследственный оператор. Сохранить оболочку K_i=(G_i,Theta_i,x_i,m_i,P_i,B_i,U_i) v0.2, расширить типизированным оператором эволюции, событий и проекции без второго канона. Для линейной задачи с внутренними I и интерфейсными B степенями свободы:
S=K_BB-K_BI K_II^{-1} K_IB; f_eff=f_B-K_BI K_II^{-1} f_I.
Это точное дополнение Шура при обратимости внутреннего блока, не универсальное coarse-решение. Решать системы, не строить inverse; в случае жестких мод учесть ограничения. В Лапласе аналогичное S(z) для LTI-оператора порождает эффективную память и вклад начального состояния. Нелинейность, изменение контакта и геометрии ограничивают оператор областью режима. DtN/Стеклова–Пуанкаре — след перемещения -> тяга (либо гидравлические порты), интегральная работа с согласованной ориентацией, диссипацией и условиями контакта. G5: K/G получать из FEM возмущений одного мира, фиксировать вход/выход, единицы, режим, область линейности, дальние связи, проверять внешнюю эквивалентность. Не постулировать кооперативную знаковую структуру.

## 2. Память
Различать материальную наследственность, эффективную память исключённых DOF, неопределённую предысторию. Для линейной системы dot x=Axx x+Axy y, dot y=Ayx x+Ayy y, исключение y даёт точное ядро Axy exp(Ayy(t-tau)) Ayx и вклад Axy exp(Ayy t)y(0). Не складывать повторно память, уже учтённую в редукции. Мори–Цванциг для нелинейных задач — отдельная квалификация.

Линейная вязкоупругость: sigma=C_inf:eps+integral C_r(t-tau):d eps(tau)+history. Для скалярного LTI с корректной предысторией Jhat(z) Ghat(z)=1/z²; ползучесть и релаксация не взаимозаменяемы. Вольтерра (MM-CREEP-101/102): ядро Абеля delta t^{-alpha}, 0<alpha<1, имеет положительную лапласовскую меру t^{-alpha}=Gamma(alpha)^{-1} integral_0^inf exp(-lambda t)lambda^{alpha-1} d lambda. SOE аппроксимирует ядро на объявленном диапазоне; слабая особенность у нуля и длинный хвост проверяются отдельно. Непрерывный спектр полностью монотонного релаксационного ядра G_inf+integral exp(-lambda t)d mu, d mu>=0; дискретизация — Прони. Тензорные условия пассивности проверять отдельно.

Для обобщённого Максвелла dot z_j=-z_j/tau_j+dot eps. При постоянной скорости на h точное обновление exp(-h/tau_j) z_j+tau_j(1-exp(-h/tau_j))dot eps. expm1 для малых аргументов, скачки деформаций требуют отдельных условий; не стирать память на событиях. Реальный H8 уже содержит maxwell_coefficients.py и maxwell_sparse_history.py: фиксированные закон, базис и support, независимые когорты закладки. Сначала проверка reuse; не заменять на generic dense tensor, не переносить коэффициенты на новый базис/группы без квалификации.

Нелинейный ряд Вольтерры: сумма причинных многовременных интегралов K_n(t;tau_1,...,tau_n)[e(tau_1),...,e(tau_n)] относительно опорной истории. Отдельные мгновенные/начальные члены, конечные области сходимости, термодинамическая допустимость. Низкоранговый CP/Tucker/TT только с оценкой. Не навязывать высокие порядки. Квадратуры Любиха: sum omega_j zeta^j=Khat(delta(zeta)/h) при постоянном h; переменный h — другой метод. Сравнить direct/SOE/квадратуру на том же ядре и пути, включая разгрузку и restart.

## 3. Методы и роль
P0: существующая наследственная физика, матрично-свободное действие, устойчивые интегралы, Schur/DtN при измеренной необходимости, функции Грина как контроль линейных задач, сопряжённая чувствительность при росте размерности. P1: гомогенизация и погранслой (масштабное разделение и локальные поправки), ряды Неймана/Борна (норма возмущения/общая область), Папкович–Фадль (полосы, линейные контрольные задачи), дробные операторы и Миттаг–Леффлер при доказанном соответствии закону, порт-гамильтонова редукция при выведенной энергии. P2: сферические гармоники и Wigner D (S²/SO(3), ODF, тензорная анизотропия при данных), курвлеты, KL/PCE только с обоснованной вероятностной мерой, персистентность. Все исследовательские расширения не обязательны для AMHF.
## 4. Контроль
Split/merge и перенос состояния: проверка работы портов, массы, энергии, material history, целевых величин на нескольких путях и горизонтах. Гомогенизация не доказывает устойчивость локальных контактов. Для голевого adjoint error estimate требуется гладкая ветвь и контроль остатка/высших членов; оценка не автоматически строгая граница. Если ошибка неприемлема, локальное уточнение или детальный solve. Не калибровать коэффициенты по holdout. Источники и локаторы — existing catalogue, PRIVATE карта материалов; не утверждать прочтение оригиналов без байтов.
