# Пространственные эталоны AMHF-R3

В этом каталоге выполните последовательно python check_spatial.py и python check_coupled_numeric.py. Первая проверка воспроизводит 22 аналитических результата, вторая интегрирует две истории нагрузки и строит рисунок. Разность 0,766 мм относится к условному сечению. Полная предлагаемая редакция и таблица требований доступны в поставке PRIVATE за 27.11.2026.
