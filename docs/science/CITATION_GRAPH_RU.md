# Граф цитирований корпуса ВКМ/СКРУ-1 (поток CITATIONS)

Дата: 26.09.2026. Фаза: информационная и архитектурная, без численных расчётов. Здесь не пересчитывались формулы и значения, не интерполировались и не усреднялись данные. Все выводы касаются происхождения утверждений, то есть того, кто у кого что взял.

## 5. Главные находки по линиям повторов (`repeated_secondary_citations.csv`)

1. **LIN-10. Конфликт значений InSAR внутри одной группы.**
   - Статья VKM-SRC-004 (2023, стр.7): «вокруг провала скорости оседаний достигают **320 мм/год**»; севернее пр. Ленина в 2021 г. — **250**, в отдельных точках **300 мм/год**.
   - Диссертация VKM-SRC-003 (2023, стр.62): почти тот же текст, но **255 мм/год** и **200/230 мм/год**. Подпись рисунка при этом ссылается на ту же статью.
   - Проверено по текстовому слою и визуально (рендер 110 dpi, `visual_checks.csv`).
   - Обе версии сохранены; причина расхождения — UNKNOWN.
   - ВКР Филатовой пересказывает эти данные как «градиенты до 300–400 мм/год по ВКМ»: скорость названа градиентом, Березники обобщены до ВКМ.
   - Объект — Березники (БКПРУ-1), **не СКРУ-1**.
2. **LIN-01. Степень нагружения МКЦ C.**
   - Формула менялась между редакциями норм. 1992: пять коэффициентов K1…K5 и Δb. 2014: ξ, k_f, σm.
   - Одно и то же число меняло смысл. 0,3/0,4 в 1992 г. — «без/с обрушением кровли». 0,4 в 2014 г. — «сильвинит вне застройки и аномальных зон». 0,30 — для КБС в каменной соли.
   - Пороги 0,32/0,45 у Лебедевой — параметры расчёта оседаний, а не допустимые [C].
   - ВКР Филатовой определяет C = γH/σ_S: потеряны множитель (a+b)/b и коэффициент формы.
3. **LIN-06. Критерий безопасности ВЗТ сменил физический смысл.**
   - 1992: m_c ≥ [m] = 10/20 м.
   - 2011: номограмма по ηmax и краевой части мульды.
   - 2014: V_m ≤ [V_m].
   - 2024: участковые [V_m] = 3,8 м, [V_i]п = 1,5 м и категории опасности.
4. **LIN-05. «Метод переменных модулей» (E^p = E^0/[1+Ψ(t)]).**
   - Метод используют 6 статей одной школы, формулу печатает только VKM-SRC-038.
   - По аннотации оригинала (EXT-SRC-009) метод опирается на **априорные** кривые нарастания оседаний η(t). Оседания здесь — вход калибровки, а не выход модели.
   - Отсюда риск циркулярности и утечки при будущем бенчмарке прогноза.
5. **LIN-02, LIN-03. Свойства солей Барях 2008 → Лебедева 2023.**
   - Числа совпадают, но «коэффициент длительной прочности» назван «величиной длительной прочности».
   - Опущены лабораторный статус и разброс монолитов: у сильвинита КрII K_t∞ достигает 0,49–0,62.
   - В самом VKM-SRC-025 есть два разных диапазона прочности: 10–36 МПа (ВКМ) и 13–41 МПа (сводка по многим месторождениям).
6. **LIN-04.** E1 = 2,5 ГПа, которое Бельтюков приписывает Баряху 2008 ([94] = VKM-SRC-025), в тексте и OCR источника как модуль упругости **не найдено**. Ближайшие числа там — нижняя граница модуля **при растяжении** (2,5–4,5 ГПа, p.31) и модуль деформации Dу = 2,54 ГПа в табл. 4.2 (p.107; в той же строке E = 12,93 ГПа). Вывод после перепроверки 26.09.2026: E1 — эффективный начальный модуль модели автора (MODEL_CHOICE, масштаб CALIBRATED_EFFECTIVE_MODEL, область UNSTATED); атрибуция к [94] не подтверждена (ATTRIBUTION_UNVERIFIED).
7. **LIN-13, LIN-19. Граничные углы и модель мульды.**
   - δ0 = 50° — норматив ВКМ 1992.
   - δ0 = 60° — у Бабаянца, взято из белорусского норматива Старобина (ANALOGUE, лавная отработка).
   - 60–73° — расчётные «условные» углы Лобанова–Федосеева.
   - 35–49° — у Филатовой, из испанской работы, без пометки об аналоге.
   - Для СКРУ-1 вне норматива значение — UNKNOWN.
8. **LIN-24. Пересчёт LOS → вертикаль.** ИФЗ/ГИ УрО РАН **делят** на cos θ, белорусская статья (009) **умножает**. При чисто вертикальном движении умножение занижает оседания. Авторы 009 объясняют расхождения InSAR–GPS только разными интервалами; заявленная ими мм-точность их собственными данными не подтверждается.
9. **LIN-11.** Формула «предел точности InSAR 10–15 мм» — это порог **парных** интерферограмм у Бабаянца. У Гусева Г.Н. и др. он превращён в «предел точности метода».

## 7. Следствия для WorldSpec (`src/vkm_world`)

- **Провенанс.** Ссылка источника на работу вне корпуса оформляется как `SourceRef(source_id=VKM-SRC-xxx, locator=…)` с пометкой о вторичности. Первоисточник, пока его нет, не считается подтверждённым. Для `EpistemicStatus` пересказ нормы остаётся FACT («источник X утверждает»), но значение нормы для WorldSpec — ENGINEERING_ASSUMPTION или MODEL_CHOICE с указанием редакции.
- **mining/\*.py, правила.** Для C, [C], k_f, [V_m] и [m] обязательны поля «редакция нормы» и «определение». Значения разных редакций не смешивать (LIN-01, LIN-06, LIN-07, LIN-23).
- **observations/catalog.py.**
  - InSAR Березников и Соликамска — OTHER_VKM_SITE. Точность и пороги задаются по методу (пара, суммирование, PS), а не константой (LIN-11).
  - Проекция LOS — явный параметр оператора наблюдения (LIN-24).
  - Нормативная основа нивелирования СКРУ-1 отсутствует (P1: Инструкция 2004/2017).
  - Одна серия публикаций ≠ несколько независимых наблюдений (LIN-16).
- **physics/processes.py, mathmeta/models.py.**
  - Метод переменных модулей калибруется по η(t): нельзя одновременно использовать его и сравнивать прогноз с теми же оседаниями (LIN-05).
  - Реологические параметры из 016 имеют неясное происхождение (LIN-15).
  - LAB ≠ MASSIF (LIN-02–04, LIN-07).
- **geology/\*.** Геология ВКМ опирается на одну компиляцию (Кудряшов) и её недоступные первоисточники. Размеры залежи в разных источниках различаются по определению контура (LIN-08). Усреднять нельзя.
