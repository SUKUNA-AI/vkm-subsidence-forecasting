## Проверка (основная версия, IDW2, SURFACE, полная область)

Исключение скважины (LOO), удержанная внутри оболочки (16 скважин): MAE отметок контактов TKT…PDKS 6,8 / 21,5 / 20,1 / 18,2 / 21,5 / 19,7 м; мощностей 19,8 / 15,8 / 5,4 / 9,5 / 6,0 м. За оболочкой (8 скважин): 16–63 м. Блоки 1,5 км, внутри (15): 7–27 м. Абсолютная проверка по независимым отметкам устьев скв. 130 и 139 (VKM-SRC-045, система высот источника не названа; у 130 конфликт с VKM-SRC-048): 13–55 м, обе скважины за оболочкой обучающих при удержании — диагностика, не валидация.

Сравнение на одних и тех же 14 полных колонках (LOO, внутри оболочки): только полные колонки (7 скважин внутри) — MAE 21–31 м для SMT…PDKS; с отбивками неполных колонок и отсутствием ПКС (10 внутри) — 19–24 м; с полевыми ограничениями «не вскрыто» — 25–27 м при смещении −15…−21 м. Поэтому основная версия — вторая. Выбор сделан после просмотра этой разбивки; её числа для выбранного варианта нельзя считать несмещённой оценкой.

## Поверхность и высоты (направление C)

Независимых отметок устьев 29 скважин в корпусе не найдено проверенными маршрутами. Соседние опоры (ствол 2-бис +190,15; скв. 128 174,40; три графические) — DSM выше источника на 1,3–11,5 м, что согласуется с растительностью и плановой ошибкой. Система высот источников по СКРУ-1 не названа. DSM против ICESat-2 ATL08 после геоидной поправки (N ≈ −2,1 м): открытый грунт с уклоном < 5° — смещение −0,23 м, RMSE 0,95 м (n = 40); лес — +11,4 м. Ни одна спутниковая точка не допущена как контроль устьев. Главный источник неопределённости — плановая привязка (разброс DSM в радиусе 90 м: медиана 8,2 м). Скв. 74 по маске воды: её отметка по DSM — уровень воды.
