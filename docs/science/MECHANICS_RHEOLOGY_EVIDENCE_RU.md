## 4. Напряжённое состояние

Каталог содержит 64 строки (σv, σh, λ, ориентация, эффект Кайзера, методические параметры). Для СКРУ-1 **нет ни одного
измерения** начального поля напряжений (открытый вопрос EV-VN-S029-0393). Имеющийся набор гипотез (MR-CONF-009):

* λ = 0,6 — гидродомкрат + АЭ, БКПРУ-2, ≈350 м, КрII (Бельтюков, VKM-SRC-029, с. 128–129) — измерено, одна площадка;
* λ = 0,71 — керновый эффект Кайзера ГИ УрО РАН (Асанов–Токсаров [62]; цитируется Лебедевой и Бельтюковым) — метод
  критикуется самим Бельтюковым;
* λ = 1 — модельный выбор (Соловьёв §6.7; Ломакин 2022), λ = 0,45 — Соловьёв §8.4.3 (слои кровли);
* 1,2–1,5 γH горизонтальных — Филатова со ссылкой на карьерную (Кольскую) работу (NON_VKM, вторично);
* 0,9–1,0 — Гремячинское месторождение, ~1 100 м (OTHER_POTASH_SITE);
* σv на СКРУ-3 (панель 12): 6–8 и 8,3–8,9 МПа вдали, до 26,5 МПа в опорной зоне; σh 5,0 МПа;
* ориентация σHmax по вывалам нефтяных скважин Соликамской впадины (1,9–2,4 км): азимуты 225–300°;
  σHmax 25–40 МПа < σv 50–60 МПа на этих глубинах (внутреннее противоречие статьи, MR-CONF-024).

## 6. Интерфейсы, повреждение, разрушение

Синтез (tier A, 21 строка) с причинной ролью для 3D+time мира оседаний:

1. **Глинистые прослои** снижают прочность образцов (−20 % при одном прослое в середине; почти в 4 раза при прослое у
   торца; −70 % при суммарной мощности ~13 мм; стабилизация 0,3–0,4 σсж) и несущую способность целиков (три нижних
   прослоя определяют эффект; нормативный множитель K3) → рост степени нагружения C → рост скорости ползучести
   целиков → рост скорости оседаний. LAB + МОДЕЛЬ + НОРМАТИВ; геометрия прослоев по панелям СКРУ-1 — UNKNOWN.
2. **Контакты напластования** — «слабейшее звено» (лаборатория): разупрочнение, дилатансия, скоростная прочность,
   ползучесть выше порога τн = 0,43σ. Натурных параметров нет.
3. **Расслоение кровли по «коржам»**: критическое смещение Uкр = 0,1045Lр·exp(−0,256Σmi/n) в двух источниках;
   для **СКПРУ-1, СКПРУ-2, СКПРУ-3, БКПРУ-1** прямо указано постадийное обрушение пачки слоёв кровли по мощным (1–5 см)
   глинистым прослоям до высоты 0,7a (VKM-SRC-037, с. 169) → рост высоты камер/целиков.
4. **Междупластье** (многопластовая отработка АБ + КрII, актуально для СКРУ-1): порог Cмп ≤ 0,2, критическая
   деформация 0,3hмп/min(a); **полевой факт** — разрушение междупластья в 1984–85 гг. дало резкий рост скоростей
   оседаний над блоком 129 (VKM-SRC-021; рудник в извлечённом тексте не назван); на БКПРУ-4 расслоения ≤ 20 мм.
5. **Режимы целиков** («жёсткие»/«податливые»; прогрессирующая ползучесть после критической деформации ≈5 %;
   накопление нарушенности → ускорение) — НОРМАТИВ + FIELD (аналог).
6. **Массовое разрушение целиков на СКРУ-2 5 января 1995 г.** (землетрясение Ms 4,2; оседание 4,5 м, мульда 650×850 м,
   провалы) у целика СКРУ-1–СКРУ-2 при C ≈ 0,32–0,36 в зоне фациального замещения пласта В; последующее развитие провала
   рядом с межшахтным целиком снизило свойства целика в модели Лебедевой. Для СКРУ-1 — граничный аналог катастрофического
   режима.
7. **Ускоренное (против расчётного) оседание в юго-восточной части шахтного поля СКРУ-1 (район блока № 115)** в
   Володинской зоне разломов и техногенная сейсмоопасная зона (Кудряшов, VKM-SRC-011, с. 32) — **единственное
   сайт-специфичное свидетельство пространственной неоднородности скорости оседаний СКРУ-1, связанной с ослабленной
   зоной**; величины и даты в источнике не приведены.
8. **ВЗТ**: механизмы (сдвиговые трещины снизу, растяжение у кровли ВЗТ при больших оседаниях, расслоение по
   контактам) и критерии (Kt, τmax/τпр, η*/H, m_c, Gc = 1 000 Па·м) — только МОДЕЛЬ/НОРМАТИВ; прямых наблюдений
   состояния ВЗТ нет (измеряется только поверхность, VKM-SRC-035).
9. **Затопления** БКПРУ-3 (1986), БКПРУ-1 (2006) → провалы 2007–2011; СКРУ-2 — приток надсолевых вод с 2014 г.,
   провалы 2014 и 2018 гг. (≈800 м от межшахтного целика; прогноз новых провалов в 400–450 м к северо-западу).
   Катастрофический режим — не нормальный режим СКРУ-1.
10. **Зоны повреждения** приконтурной части целиков по георадару (СКРУ-3, одна съёмка, гипотеза роста с возрастом
    целика) — кандидат оператора наблюдения деградации целиков; лабораторные индикаторы (дилатансия 0,6–0,8σпр,
    коэффициент нарушенности Pv) — LAB.
11. **Газодинамические явления**: на СКРУ-1 наибольшее число выбросов — в местах повышенной мощности 6-го слоя пласта
    Вк; при буровзрывной отработке карналлита на СКПРУ-1 и БКПРУ-1 — до 500 явлений в год; локальный фактор, а не
    драйвер оседаний (кроме динамического разрушения целиков).
12. **История СКРУ-1**: вывалы карналлита в выработках Первого рудника (статья 1937 г., содержание не в корпусе);
    течи в стволе № 2 в 1930 и 1935 гг.

Строки tier B (429) — записи сплошного прочтения с автоматическим (по ключевым словам) классом и пометкой
«AUTO_ASSIGNED — verify»; строки tier C (36) связывают группы количественных значений механического каталога.

## 7. Конфликты (главное)

* Длительная прочность: K_дл по Баряху (к. соль 0,60–0,65; сильвинит 0,35–0,40; карналлит 0,20–0,25) против
  Соловьёва (σ∞ = 0,3σсж для красного сильвинита, 0,4σсж для каменной соли), против единого коэффициента 0,3 у
  Лебедевой и верхней оценки 0,75 у Кудряшова; СКРУ-1 Монолит-1 0,36 против СКРУ-3 Монолит-2 0,52 при h/d = 2.
* Масштаб LAB→MASSIF: «близко к лаборатории / E натурный ×2» против «массив слабее в 10–20 раз».
* Время устойчивого состояния: 2020·K·√(12/Sр) (Соловьёв–Секунцов) против A = 1606·√(S/Sр) (Соловьёв 1992).
* Два разных «предела длительной прочности» в VKM-SRC-025: упругий предел на мгновенной диаграмме (гл. II–IV) и σ∞
  по ползучести (гл. VI) — смешивать нельзя.
* Единица δ ядра Абеля для контакта: напечатано «с^(α−1)», кривые в сутках — UNIT_DOUBT.
* λ: 0,6 / 0,71 / 1 / 0,45 / 1,2–1,5 — набор гипотез, СКРУ-1 не измерен.
* Кубиковая σ (табл. 6.12) против σсж (табл. 1.3) для СКРУ-1 — разные определения.
* Катастрофа 1995 г. при C в «относительно жёстком» диапазоне — C сам по себе не гарантирует устойчивость.
