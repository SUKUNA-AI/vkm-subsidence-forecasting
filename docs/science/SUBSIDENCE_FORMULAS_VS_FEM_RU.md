# Расчётные формулы сдвижения из корпуса и сверка с FEM (23.10.2026)

Что сделано: формулы расчёта сдвижения земной поверхности, применимые к ВКМ, собраны в каталог с локаторами и
сверены по изображениям страниц; реализованы на MATLAB и Python с тестами; применены к тем же сценариям, что 2D-расчёты
MAPDL (панель КрII 600 м, глубина ≈ 321–327 м, мощность 5,5 м, извлечение 37,8 % и 51 %, закладка). Подробный отчёт с
числами и графиками — PRIVATE `12_work_exports/formulas_vs_fem_20261023/RESULT_FORMULAS_RU.md`.

Все результаты — нормативный расчёт по формулам или модельный результат FEM; не наблюдения и не валидация.

## Каталог

[`catalogues/mathematics/subsidence_calc_formulas.csv`](../../catalogues/mathematics/subsidence_calc_formulas.csv) —
114 формул (public-safe копия PRIVATE `11_evidence_vnext/canonical/FORMULAS/SUBSIDENCE_CALC_FORMULAS.csv`, без цитат):
источник, страница, номер формулы, обозначения и единицы, область применения, статус (NORMATIVE / EMPIRICAL /
SEMI_EMPIRICAL / THEORETICAL), отношение к ВКМ (`vkm_relevance`: нормативная методика ВКМ, эмпирика ВКМ, исследования
ВКМ, аналог — угольные учебники и зарубежные статьи), итог визуальной сверки и связь с реестром
[`MATHEMATICAL_MODEL_REGISTRY.csv`](../../catalogues/mathematics/MATHEMATICAL_MODEL_REGISTRY.csv).

Основные группы:

- действующие «Указания» ВКМ в изложении VKM-SRC-065 и VKM-SRC-012: η = m₀·ω·p·k, неполная подработка f0(χ),
  типовые функции S, S′, S″ (табл. 4), наклон, кривизна, горизонтальная деформация, приведение к 15 м;
- руководство 1990/1992 (VKM-SRC-037 §8.5): η0 = 0,9·ΣS/(a + b), закладка, ξ0 = a·η0, табл. 8.26, ВЗТ;
- статьи ГИ УрО РАН (VKM-SRC-077, -089, -102): L = 1,54H, i_max = η·S′max/(H·a), критерии ВЗТ по наклону;
- учебники по углю (VKM-SRC-208, -210) и зарубежная статья (VKM-SRC-131): Авершин, Литвинишин–Кноте, Мюллер,
  коэффициенты подработанности, функции времени — для ВКМ это ANALOGUE.

Найденные несоответствия источников (опечатка L² в (8.138), подпись «Итого» в табл. 8.26, знаки в функциях времени
(1.5)/(1.7), S′(0) = 1,00 в табл. 4, редакции граничного угла 50°/55°) записаны в колонках `visual_check_note` и
`conflicts`.

## Выводы (кратко)

1. Нормативная конечная амплитуда для сценариев FEM — порядка 2 м (η = 0,9·m·ω при C ≥ 0,32); упругий FEM даёт
   миллиметры–сантиметры, ползучесть за 40 лет — до десятков процентов нормативной величины.
2. Передача «сближение пласта → поверхность» в FEM согласована с нормативом (максимум ≈ 0,9 сближения, объём мульды
   равен объёму сближения); расхождение — в величине сближения (упругость без закрытия камер, LAB ≠ MASSIF).
3. Упругая мульда шире и положе нормативной (эквивалентный угол Кноте ≈ 36–41° вместо 55°).
4. Для проверки в спецчасти пригодны: нормативная амплитуда, L = H(ctg δ0 + ctg ψ), опубликованный пример наклонов,
   приведение деформаций к базе 15 м, предельная мощность слоя соли ВЗТ (8.144). Функции времени «Указаний» — только
   после сверки с первичным текстом.
