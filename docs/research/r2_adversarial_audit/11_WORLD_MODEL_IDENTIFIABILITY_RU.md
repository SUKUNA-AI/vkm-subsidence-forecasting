# R2 · Идентифицируемость параметров физического мира

Классы:

- **DIRECTLY_IDENTIFIED** — значение прямо дано источником для объекта (хотя бы фрагментарно).
- **BOUNDED_BY_SOURCE** — источник даёт диапазон/распределение на подходящем масштабе.
- **WEAKLY_CONSTRAINED** — есть косвенные или лабораторные данные с существенным риском переноса.
- **PRIOR_ONLY** — только литературный prior (другие объекты/общие законы).
- **UNIDENTIFIED** — значение в корпусе не найдено, но в принципе измеримо (запрос MER).
- **UNIDENTIFIABLE_FROM_AVAILABLE_DATA** — даже при идеальной обработке имеющихся данных параметр не отделяется от других (компенсация/вырожденность).

Главная оговорка: карта оседаний и интервальные профили **не определяют** однозначно модуль упругости, закон ползучести или напряжения. Поверхность видит интегральный отклик: одинаковое оседание дают разные сочетания m, ω, закладки, E, η(σ) и хронологии.

Практическое следствие: при построении ансамбля миров следует **не** искать «лучший мир», а принимать множество миров, совместимых с поверхностными ограничениями (см. 15_PHYSICAL_WORLD_CONTRACT_DRAFT). Любые утверждения вида «E массива СКРУ-1 определён по InSAR/нивелированию» в текущих данных необоснованны.
