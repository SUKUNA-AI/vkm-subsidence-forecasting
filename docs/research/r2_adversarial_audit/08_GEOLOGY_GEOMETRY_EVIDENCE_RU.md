Решатель не строится, параметры не генерируются, неизвестное не заполняется «типичными значениями». Каждая строка — в [07_PHYSICAL_EVIDENCE_INVENTORY.csv](07_PHYSICAL_EVIDENCE_INVENTORY.csv) (PE-001…PE-021).

## 2. Структурные элементы и гидрогеология

- Региональная тектоника: Соликамская впадина Предуральского прогиба; пликативные дислокации до сотен метров; внутрисоляные складки до 20–30 м с западной асимметрией; крупные дизъюнктивы дискуссионны; будинаж маркирующей глины блоками 4–12 м (SRC01 §2.2.2, regional, качественно).
- Аномальные зоны КрII (AZOPOL/AZOLIN): для 12 участков есть атрибуты «аномальная зона I группы» (рис.16) и координаты центров; сами полигоны — только растр (рис.24).
- База разломов Соликамской впадины (Трапезников, Галинова, 2024) использовалась в ГИС Филатовой, локально отсутствует.
- Водоносные комплексы над солью (верхняя пермь, Q) — качественно; мощность ВЗТ по участкам СКРУ-1 — нет; минимум 13.5 м приведён для СКРУ-3. Проницаемость соли ≤1e−8 м/сут — без источника (TIER 5).

## 5. Поверхностный отклик (для совместимости миров, не для обучения)

- Накопленное оседание ~2022: легенда 0…4300 мм; 50% участков ≤500 мм, 88% ≤2000 мм (SRC01 §3.2, рис.22, 29).
- Интервальные профили Соликамска 2011–2016 (до ≈350 мм) и 2015–2016 (до ≈70 мм); карта 2016 с экстремумом ≥70 мм/год (SUP01).
- Многолетние почти линейные ряды: SRC05 рис.6б (2004–2008, ≈−18 см, нивелирование+радар) и SUP01 p.14 (2011–2016, ≈−390 мм).
- СКРУ-2 (соседний): большая часть отвода без значимых оседаний, провал 20–40 (до 60–80) мм/год, профили 80–100 мм/год (SRC04 §3.4).
- Эмпирические соотношения ВКМ: L≈1.54H (ψ=55°, δ=50°), η_ok = 0.9·ω·m_o·p (EXT03).

Эти величины — кандидаты **наблюдательных ограничений совместимости** (constraint compatibility) будущих миров. Они не идентифицируют свойства пород сами по себе (см. 11_WORLD_MODEL_IDENTIFIABILITY).
