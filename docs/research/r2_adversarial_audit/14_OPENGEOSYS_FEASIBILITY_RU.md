# R2 · OpenGeoSys — только feasibility mapping

В этом этапе OpenGeoSys **не устанавливался**, project-файлы и mesh **не создавались**, решатель **не запускался**. Возможности OGS проверены по официальной документации (EXT12): встроенные конститутивные соотношения для механики — `LinearElasticIsotropic`, `LinearElasticOrthotropic`, `Lubby2`, `CreepBGRa`, `Ehlers`, а также интерфейс `MFront`; в релизах 6.4.1/6.5.0 описана деактивация подобластей (deactivated subdomains), применяемая для моделирования выемки.

## 1. Какие процессы и модели потенциально нужны

| Потребность | Возможность OGS | Входы найдены? | Комментарий |
|---|---|---|---|
| Квазистатическая механика (SMALL_DEFORMATION) | есть | частично | Большие деформации над податливыми целиками (м) — на грани малых деформаций |
| Упругость слоёв | LinearElasticIsotropic/Orthotropic | E — prior (другой участок), ν — нет | Анизотропию/слоистость можно задать ортотропией, параметров нет |
| Ползучесть соли | Lubby2 (Бюргерс-тип), CreepBGRa (степенная, с температурой), MFront | формы — литература; числа — лаб. Нортон | Для BGRa нужна температура массива (нет) |
| Разупрочнение/пластичность | Ehlers; MFront (Мор–Кулон и др.) | c, φ — prior | Модели типа Минкли/Деринга–Киля — через MFront, возможно **custom** реализация |
| Выемка по времени | deactivated subdomains | годы — фрагмент (11 зон) | Полная хронология отсутствует → сценарная |
| Закладка и её усадка | активация подобласти + материал | тип/годы — фрагмент; A, B — нет | Реология закладки — неизвестна |
| Деградация целиков (C≈0.7, 5–7 лет) | нет прямого механизма | классы — EXT03 | Потребуется гомогенизированная «времязависимая податливость слоя выработки» (custom MFront) |
| Разрушение междупластья (реактивация) | нет прямого механизма | 1 пример (EXT04) | Сценарное событие смены свойств — custom |
| Гидромеханика (ВЗТ, рассолы) | HM-процессы есть | проницаемости, давления — нет | Вне минимального объёма |
| Температура | TH/THM | T массива — нет | Вторично на глубинах 200–400 м |

## 2. Что OGS не смоделирует напрямую

- Камерно-столбовую систему в реальном масштабе на поле ~5×5 км: камеры 5–16 м, целики 6–12 м → нужна **гомогенизация** слоя отработки (эквивалентный материал с параметрами ω, C, закладки), как в практике «переменных модулей» ГИ УрО РАН (SRC06, EXT08).
- Эмпирические типовые кривые мульд ВКМ (S(z), L≈1.54H) — это не входы, а **проверочные ограничения** для выходов OGS.
- Наблюдательные операторы (нивелирование, радар LOS/сезонность/термика крыш) — постпроцессинг вне OGS.

## 3. Где понадобятся literature priors и preprocessing

- Priors: E/ν/ρ по слоям, законы и параметры ползучести, K0, усадка закладки, время разрушения податливых целиков.
- Preprocessing: векторизация и 3D-экструзия блоков по глубинам кровли (из растров — WEAK), назначение зон «отработано/закладка» по годам, построение стратиграфических поверхностей (без скважин — плоскопараллельная схема с региональными мощностями).

## 4. Концепция графа/mesh (§31)

HNSW и иные графы ближайших соседей **не являются** физическим графом. Будущая структура — геометрически вложенный mesh:

| Сущность | Содержимое | Что из локальных данных может её заполнить |
|---|---|---|
| nodes | координаты (x, y, z) + состояние (u, σ, ε, внутренние переменные) | x, y — растровые контуры и 8 якорей (местная СК); z — глубины кровли 11 зон, региональные мощности |
| elements | связность + материал + зона | материал — prior по пласту; зона — «отработано в году t», «закладка в году t», C |
| interfaces | контакты/слоистость («коржи», глинистые прослои) | только качественно (SRC01, EXT01); параметров нет |
| time | активация/деактивация, изменение свойств | годы отработки/закладки 11 зон; снимок 2022; блок 129 |
| observation | поверхностные узлы → операторы нивелирования/радара | профили SUP01 (без координат), карта 2016 (растр), сезонность радара |

## 5. Роль PhysicsNeMo (§32) — только будущее

Цепочка: OGS/FEM → доверенные прямые расчёты → набор физических миров → (опционально) суррогат (MeshGraphNet/нейрооператор) → массовая генерация.

Ограничения: PhysicsNeMo не устанавливался и не запускался. Суррогат ускоряет повторение **уже заданной** физики; он не устраняет незнание законов ползучести, свойств и хронологии. При текущей готовности (WEAK) суррогат обучался бы на prior-driven мирах и наследовал бы все допущения. Оправдан только после того, как OGS-ансамбль покажет устойчивые выводы и потребуется масштабирование числа миров.

## 6. Реалистичность OpenGeoSys-ансамбля

Технически реалистичен как **2D/2.5D гомогенизированный** ансамбль по профилям (плоская деформация, как в SRC06) с prior-параметрами и сценарной хронологией; 3D-мир всего поля при текущей геометрии — нереалистичен без MER-03/MER-04. Научная ценность — проверка прогнозных методов на физически согласованной динамике (ползучесть, деградация целиков, закладка), а не калибровка СКРУ-1.
