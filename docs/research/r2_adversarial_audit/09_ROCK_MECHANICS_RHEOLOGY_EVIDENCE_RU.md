## 2. Реология и ползучесть

### A. Свидетельство, что ползучесть существует

- SRC01 §2.3: времязависимые деформации солей, ползучесть и релаксация (качественно, без ссылки).
- EXT05, EXT02: лабораторные и натурные наблюдения ползучести соляных пород (установившаяся стадия; конвергенция выработок).
- Поверхность: многолетнее продолжение оседаний над участками, отработанными в 1930–1970-х (SRC01 рис.17 + рис.22; EXT04 блок 129: 3.2 м сейчас, 5.8 м прогноз) — косвенно указывает на длительные процессы. Но на старых участках СКРУ-1 вклад могут давать **деградация целиков, усадка закладки и разрушение междупластья**, а не только ползучесть соли (EXT03, EXT04). Разделить эти вклады по имеющимся данным нельзя.

### C. Фактические параметры сайта/региона

- EXT02 (Морозов 2021): Нортон, установившаяся ползучесть, 30 образцов, одноосно, σ/σпр ≈ 0.4–0.8; сильвинит k = 3.18·10⁻¹⁷ МПа⁻ⁿ·сут⁻¹, n = 10.93 (R² = 0.97); карналлит k = 9.35·10⁻¹⁷ МПа⁻ⁿ·сут⁻¹, n = 6.22 (R² = 0.93). Месторождение образцов в статье прямо не названо (исходные данные — работа по Гремячинскому и Верхнекамскому). Автор сам предупреждает, что лабораторные параметры могут отличаться от массивных.
- Риск: при глубине 250–300 м σv≈6–7.5 МПа, т.е. σ/σпр≈0.25–0.3 для UCS≈26 МПа — **вне** испытанного диапазона. Экстраполяция закона с n≈11 на порядок меняет скорость.

### D. Сейчас не идентифицируемы

Массивные параметры ползучести, первичная ползучесть, температурная зависимость (температура пород не найдена; есть только воздух выработок 16–18 °C), параметры разупрочнения/повреждаемости, реология закладки и её усадка, время разрушения податливых целиков для конкретных блоков. Конвергенция «2–4 мм/сут» из SRC01 опирается на аналитическую модель другого объекта и не используется.

## 4. Режимы целиков и эмпирические соотношения (региональная база)

- EXT03: C ≤ 0.4 — «жёсткие» целики (длительная устойчивость); C = 0.7 — «податливые», обычно разрушаются в первые 5–7 лет; скорости оседания до ~800 мм/год в первые годы после выемки (БКПРУ-2). Классы Филатовой (жёсткие 0.3–0.7) этому противоречат (R2-X10).
- EXT03: L = H(ctgψ + ctgδ) ≈ 1.54H при ψ=55°, δ=50°; η_ok = 0.9ω·m_o·p, p = 1 − A(1 − B).
- Для зон СКРУ-1 из рис.17 C = 0.14–0.33 → «жёсткий» режим по EXT03; это согласуется с медленными почти линейными современными оседаниями над старыми участками (качественно; AMBIGUOUS).
