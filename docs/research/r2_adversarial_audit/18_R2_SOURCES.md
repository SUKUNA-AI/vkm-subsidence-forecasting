## 4. Замечания по цитированию в ВКР

1. SUP01 нельзя оставлять единственной ссылкой для семи численных доноров: нужна первичная публикация (статья/отчёт ПНИПУ) или явная пометка «материалы доклада, неопубликованные».
2. Физические параметры главы 2 SRC01 цитировать нельзя как параметры СКРУ-1; следует ссылаться на первоисточники (Кудряшов; EXT01–EXT04) либо не использовать.
3. Для нормативных углов/функций ВКМ предпочтителен первичный документ («Указания…», MER-09); EXT03 — допустимая рецензируемая замена для пересказа.
