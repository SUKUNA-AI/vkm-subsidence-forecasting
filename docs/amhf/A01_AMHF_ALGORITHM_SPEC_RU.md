## 2. Прямой оператор и время
Для каждого f,theta,b использовать существующий связанный L3/материальный драйвер: R(q,z;theta,B,t)=0, dot z=F; допуск остатка, событийные переходы и физические балансы. Записи в эпохах измерений + компактные выходы между ними. Неявный solve с согласованным обновлением памяти/контакта и retry из принятого состояния; вся пробная память откатывается. На каждом интервале проверять шаг/итерацию/лимит. Сохранить существующие K/G только при совпадении закона, C1/C4, базиса, режима. H8 FixedSupportHistory предпочтителен для совместимых fixed-law/fixed-basis Maxwell групп; новый fill cohort отдельно, qualified transfer либо replay при изменении support/закона/базиса. Не путать операторный редуцированный memory kernel с физическим законом. Начать с доступной принятой исторической траектории на её исходных входах для read-only постобработки и синтетических контролей; это не механика нового C1. Переход на готовый C1: сначала устранить конкретный физический блокер A02. Не строить заново геологию.

## 3. Обратная задача — конкретный метод
На выделенном calibration наборе после отдельного допуска: для семейства f и компактной допустимой theta, включающей только обоснованные параметры и параметры предыстории, минимизировать
$$J_f(\theta,b)=\tfrac12\|L^{-1}(y-H[X_{f,\theta}]-Zb)\|_2^2+\lambda\mathcal R_f(\theta),\quad R_y=LL^T.$$
Параметры масштабировать, определить границы и ограничения совместимости, regularization — MODEL_CHOICE; не объявлять prior без основания. При свободном линейном nuisance исключить его QR/SVD: W=L^{-1}, P=I-(WZ)(WZ)^+, остаток P W(y-H[X]), чувствительность P W A. При ограниченном nuisance решать совместно. При сингулярном covariance — допустимое подпространство. Не подгонять датум отдельно каждой точкой/эпохой без физического основания.

Реализация: bounded trust-region least squares / Gauss–Newton; параметрические чувствительности сначала по проверенным centered/one-sided differences на гладкой ветви, затем tangent/adjoint при измеренной необходимости. На каждом trial — допустимый физический solve; неподдержанную/негладкую ветвь отдельно, не заменять residual фиктивным нулём. Анализ ранга, профили параметров/контрастные допустимые альтернативы. Не корректировать напрямую напряжения и память произвольным фильтром. Проверять устойчивость выбора по начальным точкам, scale, regularization. Объективная причина уменьшить размерность — малая чувствительность к историческим наблюдениям или неоправданная стоимость; если будущее чувствительно, сохранять неопределённость. Ограниченная инверсия не global identification.

## 4. Отсев и прогноз
NROY existing src/vkm_world/uncertainty/nroy.py — DESIGN ONLY, не фактическая проверка. После отдельной калибровки — непересекающийся screening набор, либо screening без калибровки. Если D_approx и сертифицированная eta ограничивают ошибку D: D_approx-eta>c -> ruled out; D_approx+eta<=c -> not ruled out; иначе refine/unresolved. Эмпирические eta диагностические, не строгие сертификаты. Все пороги/ковариации/допуски зафиксировать до просмотра screening/test, не подгонять по test. При коррелированных эпохах использовать полную covariance, не независимые sequential likelihood. Сохранять незакрытые семейства отдельно. Если ничего не допущено — сообщить неадекватность модели или нехватку вычислений, не выбрать наименее плохой мир. Если часть не разрешена — отобразить неполное покрытие.

Для каждого оставшегося мира и допустимого сценария будущего B (неизвестные события не выдавать за факт) продолжить с принятого checkpoint до t0+H. Прогнозная достаточность: анализ A_eff=P R^{-1/2} A S по всей истории и B_H=DJ_H S на будущем выходе; малые исторические направления с большим B_H требуют сценарного разброса/новой информации. S — физически обоснованное масштабирование. SVD локальный, глобально сравнивать альтернативные траектории; вычислительная адаптация уменьшает ошибку представления, не незнание геологии. Минимаксный интервал скалярного выхода не менее половины истинного диаметра; sampled extrema не гарантируют coverage.

## 5. Операторы поверхности и проверка гипотез
Фиксированный носитель, s=-u_z, v=partial_t s, Hess evolution T03. Сначала совместимые эпохи/профиль, гладкое вариационное восстановление и manufactured solutions. Без точности/регулярности — не выдавать Hess. Максимум, движение экстремума, coarea, нормированные приращения, Sobolev shape, удаление ограниченных переноса/вращения; приращения = интеграл скорости плюс jumps. G3: индексы диагностические, сравнить прогноз с/без формы на тех же исходных данных, с causal features и контролями шум/датум/фронт/неизменная форма. RC-T2A/G1/RC-T4/RC-T5 обязательные вопросы, G5 обеспечивает взаимодействия, но не обязательная новая библиотека. Не вводить комплексные математические методы ради числа формул.
