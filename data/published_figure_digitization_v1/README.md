# PUBLISHED_FIGURE_DIGITIZATION_V1

Зафиксированные производные входы для проверки четырёх профилей Мусихина на
странице 15 `geokniga-02obrabotka.pdf`.

- четыре PNG являются исходными встроенными растрами PDF без изменения размера;
- CSV содержит 258 позиций ручной оцифровки, из них 252 с численным значением;
- 186 значений прочитаны по различимому маркеру или кривой, 66 отмечены как
  частично перекрытые, 6 сохранены пропусками;
- погрешность в CSV относится только к считыванию рисунка, а не к полевому
  измерению;
- строки не допускаются как временные ряды T1 и не связаны с искусственными
  идентификаторами сети.

Происхождение и SHA-256 зафиксированы в `extraction_manifest.json`. Построение
читательского атласа выполняет `scripts/reconstruct_musikhin_profiles.py`.
