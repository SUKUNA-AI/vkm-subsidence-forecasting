# SKRU1_RECONSTRUCTION_RESEARCH_V1

Версионированное исправление метаданных и статусов родительского набора. Это данные реконструкции и симуляции, не исходные полевые измерения. Родительский commit: `2c5eec48d523cf3fbc15898b0b44ac929b9b7c14`.

## Воспроизведение

Из корня репозитория, в подготовленной среде проекта:

```bash
python scripts/repair_reconstruction_data.py --root .
```

Исходники и родительские таблицы проверяются до преобразования. Для второго воспроизведения:

```bash
python scripts/repair_reconstruction_data.py --root . --output work/data_repair/rebuild_b
```

Генерируемые файлы перечислены в `manifest.json`, содержимое защищено SHA-256. README не относится к генерируемым таблицам. Скрипт не меняет первичный архив, замороженные результаты и разбиения.

## Семантика

- `observed` означает наличие принятого результата уравнивания, а не попытку выполнить ход.
- `observation_origin=synthetic_monitoring_simulation` явно описывает происхождение наблюдений.
- `source_reference_year` — дата состояния, только если установлена по источнику. Она не равна дате доступности.
- `source_available_at` остаётся пустой при отсутствии подтверждения. Публикационный год не подставляется в неё.
- `scenario_plan_available_at` и `scenario_observation_available_at` — условные даты в симуляции при записанных допущениях, не фактическая история публикации данных.
- `provenance=R` — реконструкция/прокси; `S` — искусственное назначение; `R/S` — сочетание реконструкции и проектирования сети.
- `legacy_*` сохраняет прежнюю разметку для сравнения, но не управляет допуском признака.
- Неопределённость пространственных атрибутов из предыдущей версии отмечена как эвристическая; эмпирической точностью измерения она не стала.

По умолчанию используется только история и объявленный план. Дополнительное представление допускает пространственные прокси при `SIM_STATIC_KNOWN`; это не утверждение об их доступности прогнозисту в 2018 году. Проверка известной будущей даты в `select_features` действует независимо от режима. Числа 16/50 не включают 8 столбцов метаданных.

На вход оценщика подаются только перечисленные в контракте `allowed=True` поля. Не выбирать автоматически «все числовые столбцы» и не использовать `next_planned_features_all.csv` напрямую.

## Граница исправления

Исправление не доказывает пространственную точность и реалистичность временного генератора. Старые B/C runner воспроизводят родительскую версию. Для нового эксперимента требуются отдельный адаптер, протокол сценариев и результаты под новым ID.

Техническая дата начала сценария задаётся в `configs/reconstruction_research_v1.json`; это не восстановленная дата организации мониторинга. Пропуск плановой цели не переносится на следующую успешную кампанию. Текущая мгновенная доступность уравнивания — явно записанное упрощение симуляции.
