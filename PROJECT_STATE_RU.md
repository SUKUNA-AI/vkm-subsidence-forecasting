## 1. Направление (решение пользователя D-18)

```
корпус источников (PRIVATE, 39 документов)
  → evidence vNext: сплошное чтение, записи с локаторами (цитаты — PRIVATE; PUBLIC — без цитат)
  → интерпретация: явные статусы, область, масштаб, Transfer, конфликты
  → WorldSpec: мир 3D+время, независимый от решателя (Phase 1 — DESIGN; наполнение — Phase 2)
  → представление под конкретный решатель (Phase 2+)
  → операторы наблюдения: мир → нивелирование / GNSS / InSAR / GPR
  → field validation по реальным наблюдениям и предрегистрированный бенчмарк (отдельный gate)
```

Канонический физический слой — WorldSpec 3D+время, построенный на evidence. Он описывает:

- геологию, выработки и закладку;
- историю разработки во времени;
- свойства пород и реологию;
- начальное состояние и граничные условия;
- неопределённости и провенанс.

2D-сечения — только производные представления для отдельных benchmark- и verification-задач.

Роли инструментов:

- **OGS + MFront** — основная открытая ветка геомеханики и кастомной реологии соляных пород;
- **ANSYS Mechanical** — независимая промышленная FEM-сверка на согласованных benchmark-сценариях. Это не источник
  истины и не field validation;
- **gprMax** — оператор наблюдения для георадара, а не модель оседаний.

Field validation ведётся по реальным маркшейдерским, GNSS, InSAR и другим наблюдениям в пределах их применимости.

Неизвестные параметры не заменяются правдоподобными числами. Они остаются UNKNOWN или оформляются как явно
маркированный сценарный диапазон.

Особое внимание:

- временная история выемки и закладки;
- реология соли;
- начальные напряжения;
- неоднозначные и противоречивые источники.

Цепочка «скв. 75 → Physical World v1 (2D) → OGS reference case» — **SUPERSEDED** (решения D-05, D-18):

- одна скважина не описывает рудник;
- мир не привязывается к решателю.

Её артефакты лежат в ветке `legacy` (`d54025d`). Навыки аккаунта `skru1-physical-world` и `skru1-physical-evidence`
описывают отозванное направление и требованиями не являются.

     7 подземных сейсмопавильонов, летом 2022 г. добавлены 9 поверхностных (F-SKRU1-001/002, HIGH). Это канал
     наблюдений, данных которого в корпусе нет.
10. **Задержка и доступность информации.**
    - Внешний пользователь получает сведения о смещениях с задержкой от 1 до 20 лет: эпоха → отчёт → статья → книга.
    - Для прогноза в момент t0 годятся только сведения с `available_from ≤ t0`. Неточная дата сравнивается как
      интервал (год → 31 декабря, D-16).
    - Физическое событие известно на t0 только через его собственную доступность или через `revealed_by`
      (`known_physical_at`).
11. **Нормативы и редакции.**
    - Инструкция по защите рудников ВКМКС 1994 г. действовала до 15.05.2004; союзная инструкция по наблюдениям 1984 г.
      признана недействующей с той же даты; с 2004 г. действуют замещающие редакции (NORM-F-001…003).
    - Нормативная формула — правило с редакцией, а не измерение. Значения из разных редакций не смешиваются:
      например, степень нагружения C в 1992 и 2014 гг. определена по-разному.

## 5. Архитектура

WorldSpec описывает мир в четырёх слоях: мир, процессы, наблюдения, валидация. Решатели — адаптеры: адаптер
получает срез мира и возвращает производный объект со своим провенансом. Мир он не перезаписывает.

Каждый объект несёт провенанс:

- статус, тип evidence, область (scope), масштаб (scale);
- пространственную и временную опору (даты с точностью);
- неопределённость и явный Transfer.

UNKNOWN — полноправное значение. Масштаб по умолчанию — UNSTATED, и это ошибка для параметров материала.
Значение со scope SKRU1_SKRU2_PILLAR применяется только локально к целику.

Известный пробел схемы (D-18): явных объектов начального состояния и граничных условий пока нет. Сейчас они
представлены только процессами каталога физики со статусами INITIAL_CONDITION и BOUNDARY_CONDITION (PC-02, -03, -05,
-41, -48, -51). Расширение схемы — задача Phase 2.

Репозиториев два:

- PRIVATE хранит источники, OCR и полные записи с цитатами;
- PUBLIC хранит код, схемы, public-safe каталоги и документы.

Поток идёт только PRIVATE → PUBLIC, через скрипты, которые удаляют цитаты и сокращают дословные фрагменты.

Подробно: [WORLD_SPEC_VNEXT_RU.md](docs/worldspec/WORLD_SPEC_VNEXT_RU.md),
[REPOSITORY_ARCHITECTURE_RU.md](docs/architecture/REPOSITORY_ARCHITECTURE_RU.md),
[PHASE1_DESIGN_DECISIONS_RU.md](docs/governance/PHASE1_DESIGN_DECISIONS_RU.md).

## 6. Границы (что запрещено без отдельного решения)

- Интерполяция, кригинг, 3D-реконструкция и сетки — только в Phase 2, как производные объекты со статусом
  INTERPOLATION и списком MODEL_CHOICE.
- Запуски решателей (OGS + MFront, ANSYS Mechanical, gprMax), Monte Carlo и анализ чувствительности — только в Phase 2
  по отдельному плану.
- Обучение ML, прогнозный бенчмарк и калибровка по будущей test truth — только после отдельного gate с предрегистрацией.
- Аналоговые значения не становятся значениями СКРУ-1 без Transfer. LAB ≠ MASSIF; MODEL_CHOICE ≠ FACT.
- Нельзя выдавать синтетические, оцифрованные или интерполированные ряды за первичные измерения СКРУ-1.
- Мир не называется валидированным цифровым двойником СКРУ-1.
