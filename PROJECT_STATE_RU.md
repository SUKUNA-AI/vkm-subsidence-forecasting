Дата среза: 26.09.2026. Ветка работы: `research/evidence-worldspec-reset` в обоих репозиториях.

## 1. Научная цепочка после reset

```
корпус источников (PRIVATE, 39 документов)
  → сплошное чтение + evidence vNext (PRIVATE, с цитатами; PUBLIC — без цитат)
  → WorldSpec vNext: схема мира 3D+время (Phase 1: DESIGN)
  → мир, наполненный evidence, без интерполяций (Phase 2)
  → диагностические производные представления: поверхности, сетки, 2D/3D-срезы (Phase 2, INTERPOLATION/DERIVATION)
  → решатели как адаптеры: OGS, gprMax, … (Phase 2+)
  → операторы наблюдения: мир → нивелирование / InSAR / GPR
  → предрегистрированный прогнозный бенчмарк с учётом доступности данных во времени (позже, отдельный gate)
```

Прежняя цепочка «скв. 75 → Physical World v1 (2D) → OGS reference case» **отозвана**:

- одна скважина не описывает рудник, а правило выбора «репрезентативной» скважины было неустойчивым (решение D-05);
- мир не должен быть привязан к решателю.

Её артефакты сохранены в ветке `legacy` (`d54025d`) и классифицированы аудитом.

## 3. Что известно (главные научные результаты)

Статусы указаны по правилам [SCIENTIFIC_RULES_RU.md](docs/governance/SCIENTIFIC_RULES_RU.md).

1. **Координаты.** Ни один источник не называет систему координат рудника СКРУ-1 и не даёт параметров
   перехода (UNKNOWN).
   - Напечатанных координат устья нет ни у одной скважины корпуса.
   - Числовые плановые положения есть у 31 скважины. Это оцифровка центров подписей на картах Лебедевой
     в безымянной локальной сетке; статус DERIVATION, ±150–200 м.
   - Система высот названа только в общем виде: отметки от нуля Кронштадтского футштока, Балтийская
     система, эпоха не указана.
2. **Скважины.**
   - Отбивки, относящиеся к СКРУ-1, есть только у 5 скважин у междушахтного целика СКРУ-1/СКРУ-2.
   - Скв. 75 — обычное наблюдение, не представитель рудника; медоид набора — скв. 23.
   - Главный путь геопривязки — солеразведочные скважины на границе горного отвода (109/74/232/221).
     Их координаты нужно запрашивать из фондов.
3. **Атрибуция рисунков.** Рис. 10 ВКР Филатовой относится к СКРУ-2, а не к СКРУ-1.
   Атрибуция по руднику проверяется для каждого набора данных отдельно.
4. **Механика.**
   - 1415 из 1720 записей — лабораторные. Закона перехода LAB→MASSIF с доказательной базой нет:
     источники расходятся даже в направлении поправки (MR-CONF-002).
   - Единственные лабораторные реологические данные, явно отнесённые к СКРУ-1, — табл. 6.2 Баряха и др.:
     Монолит-1, КрII сл. 5. Место, глубина и дата отбора неизвестны.
   - **Закона ползучести, откалиброванного на СКРУ-1, нет.**
5. **Начальное напряжённое состояние.** Коэффициент бокового распора λ хранится как дискретный набор гипотез
   {0,45; 0,6; 0,71; 1,0} с источниками и не усредняется (D-04).
6. **Наблюдения оседаний.** Прямых наблюдений, достоверно отнесённых к СКРУ-1, три набора:
   - профильная линия 12 над блоком 201: 5 графических эпох 1992–2010;
   - InSAR ПНИПУ: карта 2011 г.;
   - InSAR ПНИПУ: ряд одной точки 2011–2016.

   Поле «ОСЕДАНИЯ_2022» из ВКР — производный интерполированный продукт с высоким риском утечки, а не наблюдение.
   InSAR на ВКМ — сезонный, одна орбита (LOS). Знак проекции LOS в источниках противоречив.
7. **Хронология выемки и закладки СКРУ-1** известна только срезом ГИС предприятия: 14 зон с датами отработки
   и закладки, факт закладки на 01.10.2022. Поблочных дат начала и окончания в корпусе нет.
8. **Аварийный сценарий.** Все затопления в корпусе относятся к другим рудникам. Для СКРУ-1 это аналог,
   а не история (сценарий ACCIDENT отделён от NORMAL).
9. **Георадар.** Данных GPR по СКРУ-1 нет. Все профили — другие рудники или без атрибуции.
10. **Задержка информации.** Внешний пользователь получает данные о смещениях с задержкой 1–20 лет:
    эпоха → отчёт → статья → книга. Это ключ к честному бенчмарку (правило `available_from ≤ t0`).

## 5. Архитектура

- Мир описывает WorldSpec в четырёх слоях: мир, процессы, наблюдения, валидация.
  Решатели — адаптеры к срезам мира.
- Каждый объект несёт провенанс:
  - статус, тип evidence, область (scope), масштаб (scale);
  - пространственная и временная опора;
  - неопределённость и явный Transfer.
- UNKNOWN — полноправное значение.
- Два репозитория.
  - PRIVATE хранит источники, OCR и полные записи с цитатами.
  - PUBLIC хранит код, схемы, public-safe каталоги и документы.
  - Поток идёт только PRIVATE → PUBLIC через скрипт, удаляющий цитаты.
- Подробно: [WORLD_SPEC_VNEXT_RU.md](docs/worldspec/WORLD_SPEC_VNEXT_RU.md),
  [REPOSITORY_ARCHITECTURE_RU.md](docs/architecture/REPOSITORY_ARCHITECTURE_RU.md),
  [PHASE1_DESIGN_DECISIONS_RU.md](docs/governance/PHASE1_DESIGN_DECISIONS_RU.md).

## 6. Границы (что запрещено без отдельного решения)

- Интерполяция, кригинг, 3D-реконструкция и сетки — только в Phase 2, как производные объекты со статусом
  INTERPOLATION и списком MODEL_CHOICE.
- Запуски решателей (OGS, gprMax), Monte Carlo, анализ чувствительности — только в Phase 2 по отдельному плану.
- Обучение ML, прогнозный бенчмарк, калибровка по будущей test truth — только после отдельного gate
  с предрегистрацией.
- Аналоговые значения не становятся значениями СКРУ-1 без Transfer; LAB ≠ MASSIF; MODEL_CHOICE ≠ FACT.
- Нельзя выдавать синтетические, оцифрованные или интерполированные ряды за первичные измерения СКРУ-1.
